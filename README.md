# 🎓 منصة مواد الترم الثاني - قسم الذكاء الاصطناعي (FCI & AI Portal)

بوابة ويب متكاملة، خفيفة وسريعة، مخصصة لطلاب كلية الحاسبات والمعلومات (قسم الذكاء الاصطناعي) لتنظيم ومشاركة كافة مواد الترم الثاني لعام 2026، مع التركيز على **مواقع الشرح التفاعلية المخصصة** لكل مادة.

---

## 🌟 مميزات المنصة

- 🎯 **تخصيص كامل لمواقع الشرح:** كل مادة تبرز موقع الشرح الخاص بها مع زر وصول مباشر وإمكانية المعاينة الحية.
- ☁️ **ربط مباشر بسحابة Google Drive:** جميع سلايدات ومحاضرات المواد (PDF و PowerPoint) متصلة مباشرة بسحابة Google Drive الرسمية بدون تضخيم حجم المستودع، مع إمكانية المعاينة المباشرة أو التحميل السريع.
- 🎬 **سكشن مخصص لشروحات الفيديو وقوائم التشغيل (YouTube Playlists):** قسم تفاعلي في كل مادة يجمع أفضل شروحات اليوتيوب المعتمدة بالعربي والإنجليزي مع إمكانية المشاهدة المباشرة داخل المنصة دون مغادرة الصفحة.
- 🎨 **ثلاثة أوضاع بصرية متكاملة (3 Themes):**
  - **الوضع الليلي (Dark Mode):** تصميم تقني بألوان مريحة وعصرية وواجهات زجاجية (Glassmorphism).
  - **الوضع النهاري (Light Mode):** تباين ناصع ونظيف للقراءة السريعة أثناء النهار.
  - **وضع القراءة الهادئ (Sepia / Eye-Comfort Mode):** درجات ورقية دافئة مصممة خصيصاً للمذاكرة لساعات طويلة دون إجهاد العين.
- 🛣️ **تقسيم المادة إلى مسارين مستقلين (Dual Pathways):**
  - **🏛️ طريق المحاضرة (The Lecture Pathway):**
    - موقع الشرح التفاعلي المعتمد (الأساس مع إمكانية المعاينة الحية المضمنة).
    - شروحات الفيديو وقوائم التشغيل المعتمدة مع إمكانية المشاهدة المباشرة.
    - سجل المحاضرات وسلايدات الدكاترة المتصل بـ Google Drive مباشرة.
    - بنك امتحانات النظري السابقة (ميدترم وفاينال) ومذكرات القوانين والمراجع.
    - عرض موعد ومدرج المحاضرة المخصص لمجموعة الطالب (B1 / B2 / B3).
  - **💻 طريق السكشن والعملي (The Section & Lab Pathway):**
    - شيتات المعيدين للعملي للتحميل المباشر.
    - الأكواد البرمجية ومستودعات GitHub وروابط Google Colab.
    - التكليفات والمهام المطلوبة مع الـ Deadlines وشارات حالة التسليم.
    - نماذج امتحانات العملي وكويزات اللاب.
    - عرض موعد ومعمل السكشن واسم المعيد المخصص لسكشن الطالب (1 إلى 12).
- 👥 **تخصيص كامل حسب المجموعة والسكشن:**
  - نافذة منبثقة لاختيار المجموعة (B1 / B2 / B3) والسكشن (1 - 12).
  - جدول أسبوعي تفاعلي كامل ومخصص للطالب يوماً بيوم من السبت إلى الخميس.
- ⚡ **أداء فائق:** كود نقي (HTML5 + Tailwind CSS + Vanilla JS) يعمل فوراً بدون الحاجة لأي Node.js أو تثبيت حزم أو قواعد بيانات.

## 🛠️ كيف تعدل المحتوى بنفسك؟ (الملف المركزي `js/courses-data.js`)

كل ما تحتاجه لإضافة رابط موقع شرح، محاضرة جديدة، أو ملف هو فتح الملف التالي:
👉 `js/courses-data.js`

### 1. لتعديل رابط موقع الشرح الخاص بك:
ابحث عن المادة وعدل حقل `explanationSite`:
```javascript
explanationSite: {
  url: "https://your-actual-website-url.com", // ضع الرابط الفعلي هنا
  title: "موقع الشرح التفاعلي للمعمارية",
  description: "وصف موقعك المميز...",
  status: "متاح الآن",
  features: [
    "ميزة 1",
    "ميزة 2"
  ]
}
```

### 2. لإضافة محاضرة جديدة:
داخل مصفوفة `lectures`:
```javascript
{
  id: 4,
  title: "Memory Hierarchy & Caches",
  arabicTitle: "التسلسل الهرمي للذاكرة والكاش",
  week: 4,
  date: "الأسبوع الرابع",
  slidesUrl: "https://drive.google.com/...", // رابط السلايد أو الملف
  videoUrl: "https://youtube.com/...",       // رابط الفيديو
  notes: "ملاحظات هامة للمذاكرة"
}
```

## 🚀 كيفية تشغيل المنصة

1. **محلياً على جهازك:**
   - ببساطة اضغط مرتين على ملف `index.html` ليفتح في أي متصفح!
   - أو شغّل Live Server من VS Code.

2. **نشرها على الإنترنت مجاناً للدفعة:**
   - **GitHub Pages:** أنشئ مستودع (Repository) وارفع الملفات وفعل GitHub Pages من الإعدادات.
   - **Vercel / Netlify:** اسحب المجلد وأفلته في Vercel أو Netlify وستحصل على رابط عالمي مجاني وسريع في 10 ثوانٍ!
