## 🌟 مميزات المنصة

- 🎯 **تخصيص كامل لمواقع الشرح:** كل مادة تبرز موقع الشرح الخاص بها مع زر وصول مباشر وإمكانية المعاينة الحية.
- ☁️ **ربط مباشر بسحابة Google Drive:** جميع سلايدات ومحاضرات المواد (PDF و PowerPoint) متصلة مباشرة بسحابة Google Drive الرسمية بدون تضخيم حجم المستودع، مع إمكانية المعاينة المباشرة أو التحميل السريع.
- 🎬 **سكشن مخصص لشروحات الفيديو وقوائم التشغيل (YouTube Playlists):** قسم تفاعلي في كل مادة يجمع أفضل شروحات اليوتيوب المعتمدة بالعربي والإنجليزي مع إمكانية المشاهدة المباشرة داخل المنصة دون مغادرة الصفحة.
- 🎨 **ثلاثة أوضاع بصرية متكاملة (3 Themes):**
  - **الوضع الليلي (Dark Mode):** تصميم تقني بألوان مريحة وعصرية وواجهات زجاجية (Glassmorphism).
  - **الوضع النهاري (Light Mode):** تباين ناصع ونظيف للقراءة السريعة أثناء النهار.
  - **وضع القراءة الهادئ (Sepia / Eye-Comfort Mode):** درجات ورقية دافئة مصممة خصيصاً للمذاكرة لساعات طويلة دون إجهاد العين.
- 🛣️ **تقسيم المادة إلى مسارين مستقلين (Dual Pathways):**
  - **🏛️ طريق المحاضرة (The Lecture Pathway):**
    - موقع الشرح التفاعلي المعتمد (الأساس مع إمكانية المعاينة الحية المضمنة).
    - شروحات الفيديو وقوائم التشغيل المعتمدة مع إمكانية المشاهدة المباشرة.
    - سجل المحاضرات وسلايدات الدكاترة المتصل بـ Google Drive مباشرة.
    - بنك امتحانات النظري السابقة (ميدترم وفاينال) ومذكرات القوانين والمراجع.
    - عرض موعد ومدرج المحاضرة المخصص لمجموعة الطالب (B1 / B2 / B3).
  - **💻 طريق السكشن والعملي (The Section & Lab Pathway):**
    - شيتات المعيدين للعملي للتحميل المباشر.
    - الأكواد البرمجية ومستودعات GitHub وروابط Google Colab.
    - التكليفات والمهام المطلوبة مع الـ Deadlines وشارات حالة التسليم.
    - نماذج امتحانات العملي وكويزات اللاب.
    - عرض موعد ومعمل السكشن واسم المعيد المخصص لسكشن الطالب (1 إلى 12).
- 👥 **تخصيص كامل حسب المجموعة والسكشن:**
  - نافذة منبثقة لاختيار المجموعة (B1 / B2 / B3) والسكشن (1 - 12).
  - جدول أسبوعي تفاعلي كامل ومخصص للطالب يوماً بيوم من السبت إلى الخميس.
- ⚡ **أداء فائق:** كود نقي (HTML5 + Tailwind CSS + Vanilla JS) يعمل فوراً بدون الحاجة لأي Node.js أو تثبيت حزم أو قواعد بيانات.

## التطوير والتحقق محليًا

الموقع يظل Static، وملفات التنسيق والأيقونات الجاهزة موجودة داخل المستودع. الطالب لا يحتاج تثبيت Node لتصفحه. الشرح التفصيلي يُحمّل عند فتحه، وملفات Drive وYouTube تحتاج اتصالًا بالمزود وإتاحة المشاركة من صاحب المحتوى.

للتطوير استخدم Node 24 أو أحدث:

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm start
```

ثم افتح `http://127.0.0.1:8765/`. تشغيل الخادم محصور على الجهاز المحلي. يمكنك أيضًا فتح `index.html` مباشرة، وقد اختُبر تحميل المذاكرة بهذا الأسلوب في Chrome.

أوامر التحقق:

```powershell
npm run check
npm run validate
npm run lint
npm test
```

لاختبارات المتصفح، إذا كان Chrome مثبتًا على Windows:

```powershell
$env:PORTAL_BROWSER_CHANNEL = 'chrome'
npm run test:browser
```

أو ثبّت متصفح الاختبار المحدد بواسطة نسخة Playwright المثبتة ثم شغّل التحقق الكامل:

```powershell
npx --no-install playwright install chromium
npm run verify
```

الاختبارات تشغّل خادمًا مؤقتًا ومتصفحًا معزولًا، وتختبر أيضًا العمل تحت مسار `/Sem2_portal/` مثل GitHub Pages. الشبكة الخارجية محجوبة في اختبارات السلوك لضمان ثباتها؛ اختبار الروابط ومحتوى المزودين مسألة منفصلة. النتائج المحلية تحفظ في `test-results/`، وهو مستبعد من Git.

بعد تعديل ملفات HTML أو JavaScript التي تتضمن أصناف التنسيق، شغّل `npm run build` لتحديث `css/tailwind.css` وكتالوج الشرح الصغير. نسخ Tailwind وLucide وPlaywright مثبتة في `package-lock.json`؛ رخصة الأيقونات في `js/vendor/LUCIDE-LICENSE`.

التحقق الجديد يميز أخطاء البيانات عن [سجلات الجدول المعلقة](docs/PENDING-TIMETABLE.md). السجلات الثلاثة لم تُصحح بالتخمين، وتظهر رسالة للسكاشن المتأثرة. إعداد CI الجديد خاص بالبورتال، ومنظومة الأتمتة القديمة لم تُعدل.

## تصميم A1

الصفحتان الأساسيتان تستخدمان تصميم A1 مع الوظائف الحالية للموقع. الخط محلي، ومؤشر Flex يعمل على الأجهزة ذات الماوس مع الإبقاء على مؤشر الجهاز داخل القارئ وحقول الإدخال. مقدمة المعالج تظهر على الرئيسية مرة في جلسة المتصفح للشاشات المناسبة، ويختفي شريط التنقل أثناءها ثم يعود ثابتًا. لتجربتها مجددًا محليًا افتح `http://127.0.0.1:8765/?intro=processor`.

اختبارات التصميم الإضافية تعمل عبر `npm run test:a1`، وهي ضمن `npm run verify`. النتائج والصور في `test-results/a1/`. تفاصيل النطاق ودليل الحفاظ على الوظائف في [خطة الدمج](docs/A1-IMPLEMENTATION-2026-10-20.md). هذه المرحلة لا تضيف حفظ تقدّم المذاكرة أو استكمال المحاولات أو البحث الشامل الواردة في الخطة المؤجلة.

تجربة الطالب الحالية تبدأ باختيار المادة، ثم نوع المصدر (محاضرات، سكاشن، فيديو، تكليفات، مصادر ومراجع). يظهر نوع واحد في كل مرة، وتظل المواعيد وهيئة التدريس والتفاصيل الإضافية قريبة دون تكديس الصفحة. القارئ يعرض سلايدًا واحدًا مع فهرس وتبويب للسلايد الأصلي؛ والكويز يعرض سؤالًا واحدًا مع الخريطة والتنقل والتصحيح الحالي. جدول الجامعة له عرض مستقل من التنقل. تفاصيل تصحيح التجربة والتحقق في [سجل رحلة الطالب](docs/A1-STUDENT-JOURNEY-2026-10-21.md).
