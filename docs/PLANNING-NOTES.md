# ملاحظات تمهيدية للخطة

بتاريخ 20 أكتوبر 2026، بناءً على توجيه المستخدم:

- منظومة الأتمتة خارج نطاق التركيز والخطة الحالية.
- الشرح التفاعلي الداخلي متوفر حاليًا لمحاضرتين فقط في قواعد البيانات.
- بند جانبي للخطة: أزرار الشرح التفاعلي الداخلي غير المتوفر تظهر بحالة «قريبًا»، ولا توحي بأن المحتوى متاح أو تفتح شرحًا غير موجود. روابط المصادر والمواقع الخارجية خارج نطاق هذا البند.
- هذه ملاحظات للتخطيط فقط؛ لم يُنفذ تغيير في الواجهة. الخطة التفصيلية ستُبنى مع المستخدم لاحقًا.
