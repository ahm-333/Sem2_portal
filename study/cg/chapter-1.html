الجزء الأول (Part 1): مقدمة وتطبيقات الرسم بالحاسوب (Intro & Applications)

1. يعني إيه أصلاً Computer Graphics؟

التعريف بالإنجليزية:

"Computer graphics is concerned with all aspects of producing pictures or images using a computer."

توضيح:

هو أي حاجة ليها علاقة بإنك تطلع صورة أو رسمة من الكمبيوتر. سواء صورة ثابتة، أنيميشن، لعبة، أو زرار بتدوس عليه.

تاريخه بدأ إزاي؟ (History)
من 50 سنة: الموضوع بدأ متواضع جداً (humbly)؛ مجرد شوية خطوط بتترسم على شاشة مدفونة اسمها CRT (Cathode Ray Tube).
دلوقتي: وصلنا لمرحلة بنعمل صور بالكمبيوتر مستحيل تفرق بينها وبين الصور الحقيقية (Indistinguishable from photographs of real objects).

2. إحنا بنستخدم الـ Computer Graphics في إيه؟ (Applications)

المحاضرة قسّمت تطبيقات الجرافيكس لـ 4 مجالات رئيسية لازم تكون حافظهم وعارف تفاصيل كل واحد:

تطبيقات الجرافيكس الأربعة (4 Major Application Areas)
1. عرض المعلومات (Display of Information)
2. التصميم (Design)
3. المحاكاة والتحريك (Simulation and Animation)
4. واجهات المستخدم (User Interfaces)
المجال الأول: عرض المعلومات (Display of Information)

العلماء والباحثين بيعملوا تجارب ويطلعوا أرقام بالملايين (Data). هل هيفهموا الأرقام دي لو فضلت في جداول؟ لأ طبعاً!

هنا بيظهر مفهوم مهم جداً اسمه: التصور العلمي (Scientific Visualization).
تعريفه: إعطاء أدوات رسومية (Graphical tools) للباحثين لتحويل البيانات المجردة إلى أشكال هندسية معروضة (Geometric entities)، وده بيخليهم يفهموا العمليات المعقدة بمجرد النظر.
أمثلة بتيجي في السلايدات:
1. سريان الموائع وحركة الهوا والسوائل (Fluid flow).
2. البيولوجيا الجزيئية وشكل شريط الـ DNA والبروتينات (Molecular biology).
3. الرسوم الرياضية للمعادلات المعقدة (Mathematics).
المجال الثاني: التصميم (Design)

المهندسين والمعماريين شغلهم كله قايم على التصميم.

المهندس بيبدأ بمجموعة مواصفات وشروط (Specifications)، وبيدور على حل رخيص ومناسب يرضي الشروط دي (Cost-effective solution).
قاعدة مهمة جداً بتيجي في أسئلة الامتحان:
عملية التصميم هي عملية تكرارية (Iterative process)؛ يعني مش من أول رسمة بنوصل للحل. المهندس بيعمل تصميم، يجربه، يعدل، ويجرب تاني لحد ما يظبط.
أنواع مشاكل التصميم في الواقع نوعين:
1. Overdetermined (فوق المحدد / شروط زيادة عن اللزوم): مشكلة عليها قيود وشروط كتير جداً ومتضاربة لدرجة إنه مفيش ولا حل يقدر يرضي كل الشروط دي في نفس الوقت (Possess no solution that satisfies all criteria).
2. Underdetermined (أقل من المحدد / شروط مفتوحة): مشكلة شروطها قليلة وبسيطة، وبالتالي ليها حلول كتيرة جداً كلها تنفع وترضي المعايير (Have multiple solutions that satisfy design criteria).
الأداة السحرية للمصممين: الـ CAD
اختصار لـ Computer-Aided Design (التصميم بمساعدة الحاسوب). بتدخل في 3 مجالات رئيسية في السلايد:
1. العمارة وتصميم المباني (Architecture).
2. تصميم الأجزاء الميكانيكية للسيارات والماكينات (Design of mechanical parts).
3. تصميم الدوائر الإلكترونية المتكاملة فائقة الكبر (VLSI circuits - Very-Large-Scale Integrated).
المجال الثالث: المحاكاة والتحريك (Simulation and Animation)
أول ما أجهزة الجرافيكس طوّرت وبقت قادرة ترسم صور معقدة في نفس اللحظة بدون تأخير (Real-time)، بدأ التفكير في استخدامها في المحاكاة (Simulators).
محاكي الطيران (Flight Simulator) — ليه مهم وبيصرفوا عليه ملايين؟
1. بيزود الأمان (Increase safety): لو الطيار غلط في المحاكي مش هيموت!
2. بيقلل تكاليف التدريب جداً (Reduce training expenses): مفيش بنزين طيارات ولا استهلاك محركات.
محاكي قيادة السيارات (Driving Car Simulator): لتدريب السائقين واختبار الطرق.
ألعاب الفيديو (Arcade Games): بسبب استخدام شرائح الـ VLSI المتطورة، ألعاب الفيديو بقت متقدمة ومبهرة زي محاكيات الطيران بالظبط.
المجال الرابع: واجهات المستخدم (User Interfaces - GUI)

طريقتنا في التعامل مع الكمبيوتر اتغيرت؛ زمان كانت شاشة سوداء وتكتب أوامر (CLI)، دلوقتي بقى كله شغال بأسلوب مرئي اسمه Visual paradigm.

النظام المرئي ده متكون من 4 حاجات:
1. النوافذ (Windows).
2. الأيقونات (Icons).
3. القوائم (Menus).
4. جهاز التأشير زي الماوس (Pointing device / Mouse).
كل أنظمة التشغيل (Windows و Mac) والمتصفحات (Chrome, Firefox, Safari) شغالة بنفس المبدأ ده.
ركز في دي، بتيجي في السلايد نقطة نقطة — أنواع الأيقونات (Icons) الـ 5:
1. Program icons: أيقونات لفتح البرامج.
2. Object icons: أيقونة بتمثل كائن معين (زي ملف تكست، صورة، فولدر).
3. Menu icons: زرار بتدوس عليه يفتحلك قايمة خيارات.
4. Check-Box icons: مربعات بتعلم عليها صح وغلط عشان تختار كذا اختيار مع بعض.
5. Spinner icons: السهمين الصغيرين (واحد طالع والتاني نازل) اللي بتدوس عليهم عشان تزود أو تنقص رقم معين (زي اختيار عدد النسخ في الطباعة).
ملخص سريع للجزء الأول:

1. جرافيكس = كل جوانب إنتاج الصور بالكمبيوتر.

2. 4 تطبيقات: Display of Information (زي الـ Scientific Visualization)، Design (تكراري ومعتمد على الـ CAD)، Simulation (أمان وتوفير)، User Interfaces (نظام مرئي و5 أنواع أيقونات).

Part 1: Core Concepts Summary (English Reference)

1. Definition of Computer Graphics:
  • Computer Graphics: The field concerned with all aspects of producing pictures or images using a computer.
  • Historical Milestone: Originated 50 years ago with simple line displays on a Cathode Ray Tube (CRT); today it generates photorealistic images indistinguishable from real-world photography.
2. Four Major Application Areas:
  • Display of Information (Scientific Visualization): Converts vast amounts of raw data into geometric entities (Fluid flow, molecular biology, mathematics).
  • Design (CAD): An iterative process seeking a cost-effective solution. Problems are Overdetermined (no solution satisfies all criteria) or Underdetermined (multiple valid solutions). Pervasive in Architecture, mechanical parts, and VLSI circuits.
  • Simulation and Animation: Enabled by real-time graphics rendering. Flight simulators increase safety and reduce training expenses.
  • User Interfaces (GUI): Visual paradigm (windows, icons, menus, pointing device). Five icon categories: Program icons, Object icons, Menu icons, Check-box icons, Spinner icons.

أسئلة الجزء الأول (Practice Questions - Part 1 • كويز تفاعلي بالعامية)

الجزء الثاني (Part 2): معمارية نظام الرسوميات (The Graphics System Architecture)

1. النظام الرسومي كنظام حاسوبي (The Graphics System)

قاعدة حتمية من السلايدات:

"A computer graphic system is a computer system; as such, it must have all the components of a general-purpose computer system."

توضيح: أي جهاز بيعمل جرافيكس هو في الأصل كمبيوتر، وعشان كدة لازم يحتوي على المكونات الأساسية لأي كمبيوتر عام.

المكونات الستة الرئيسية لنظام الرسوميات (The 6 Major Elements):

المحاضرة حطت رسمة معمارية (Block Diagram) بتتكون من 6 عناصر أساسية لازم تكون عارف مسار كل واحد فيهم:

رسمة المعمارية الأساسية لنظام الرسوميات (The 6 Major Elements Block Diagram):
1. Input devices: زي الماوس والكيبورد وعصا التحكم.
2. CPU (Central Processing Unit): العقل المدبر للنظام ككل.
3. GPU (Graphics Processing Unit): المعالج المخصص لحسابات الرسوميات.
4. Memory: ذاكرة الجهاز الرئيسية لتخزين البرامج والبيانات.
5. Frame buffer: ذاكرة مخصصة ومهمة جداً لتخزين ألوان البكسلات.
6. Output devices: شاشة العرض (زي الـ CRT زمان أو الشاشات الحديثة).

2. البكسلات ومفهوم الـ Frame Buffer (Pixels & The Frame Buffer)

ده قلب المحاضرة، ركز فيه جداً:

يعني إيه Raster و يعني إيه Pixel؟
الشاشة اللي قدامك مش لوحة رسم ناعمة؛ الشاشة عبارة عن شبكة (مصفوفة) مستطيلة من النقاط، المصفوفة دي اسمها علمياً الـ Raster.
كل نقطة صغيرة جوة المصفوفة دي اسمها Picture Element، واختصارها هو Pixel (أو بتسمى قديماً Pel).
تعريف الصورة في السلايد:

"An array (the raster) of picture elements, or pixels, produced by the graphics system."

ما هو الـ Frame Buffer؟
هو مش شاشة ومش بروسيسور؛ هو جزء مخصص في الذاكرة (A part of memory).
وظيفته الحتمية: تخزين قيم وألوان كل بكسل موجود على الشاشة. كل نقطة على شاشتك ليها مكان مناظر ليها في الـ Frame Buffer بيحدد لونها إيه حالياً.

3. عمق البكسل وحسابات الألوان (Pixel Depth & Color Precision)

السؤال البديهي: البكسل الواحد بيتخزن في قد إيه من الذاكرة؟ وده اللي بنسميه:

Pixel Depth (أو Precision):

"The number of bits that are used for each pixel."

الكمبيوتر شغال بنظام ثنائي (Binary: إما 0 أو 1). بالتالي، لو خصصت للبكسل n من البتات، عدد الألوان المتاحة للبكسل بيتحسب بالقانون ده:

Number of Colors = 2n
جرب بنفسك: اضغط على أي عمق بكسل (n bits) لتشوف عدد الألوان ونوع النظام: n = 24 bits → 16,777,216 colors (Full-Color System)
الحالات المذكورة نصاً في السلايدات (مهمة جداً للامتحان):
1. نظام الـ 1-bit (يُسمى Bitmap):
• البكسل واخد بت واحد بس (n = 1).
• عدد الألوان = 21 = 2 (إما On أو Off، يعني أبيض أو أسود فقط). بيسموه 1-bit bitmap.
2. نظام الـ 4-bits:
• البكسل واخد 4 بت ⟹ عدد الألوان = 24 = 16 لوناً مختلفاً.
3. نظام الـ 8-bits:
• عدد الألوان = 28 = 256 لوناً.
4. نظام الـ 15-bits:
• عدد الألوان = 215 = 32,768 لوناً.
5. نظام الـ 16-bits:
• عدد الألوان = 216 = 65,536 لوناً.
6. نظام الـ 24-bits (أو أكثر):
• عدد الألوان = 224 = 16,777,216 لوناً (حوالي 16.7 مليون لون).
• النظام ده بيتسمى في السلايدات: Full-Color System.
• خاصيته: بيعرض ألوان كافية لتمثيل معظم الصور بواقعية تامة ومطابقة للحقيقة (Represent most images realistically).

4. دور الـ CPU مقابل الـ GPU في النظام الرسومي

في الأنظمة البسيطة والقديمة (Simple system): كان بيبقى فيه معالج واحد بس وهو الـ CPU، وكان عليه يشيل كل حاجة: المعالجة العادية بتاعة البرامج، ومعالجة الجرافيكس.
في الأنظمة الحديثة: بقى عندنا معالج رسومي مخصص وهو الـ GPU.
ما هي الوظيفة الجوهرية للمعالج الرسومي؟ (The graphical function)

"The graphical function of the processor is to take specifications of graphical primitives and to assign values to the pixels in the frame buffer."

توضيح: المعالج الرسومي وظيفته ياخد الأشكال الهندسية الأساسية (Graphical Primitives) زي النقاط والخطوط والمثلثات اللي المبرمج كاتبها في الكود، ويحولها إلى قيم ألوان تتحط في البكسلات جوة الـ Frame Buffer (العملية دي بنسميها قدام Rasterization).

5. أجهزة الإخراج وشاشات الـ CRT القديمة (Output Devices: The CRT)

لحد وقت قريب، الشاشة الأساسية المسيطرة على كل الأجهزة كانت شاشة أنبوب أشعة الكاثود: Cathode-Ray Tube (CRT).

إزاي شاشة الـ CRT بتشتغل فيزيائياً؟ (خطوات عمل الـ CRT):
1. مدفع الإلكترونات (Electron Gun): بيطلع شعاع إلكترونات عالي الكثافة والسرعة.
2. محولات الإشارة (Digital-to-Analog Converters - DAC):
الكمبيوتر شغال أرقام ديجيتال (0 و 1)، لكن تحريك الإلكترونات بيحتاج فولت وتيار تماثلي (Analog voltages). محولات الـ DAC بتاخد قيم البكسلات من الـ Frame Buffer وتحولها لفولتات كهربائية.
3. ألواح الانحراف (Deflection Plates):
فولتات الـ DAC بتطبق على لوحات انحراف أفقية (X) ورأسية (Y). المجال الكهربي للألواح دي بيوجه شعاع الإلكترونات بدقة عشان يروح للنقطة المحددة على الشاشة.
4. طبقة الفسفور (Phosphor Coating):
السطح الداخلي لزجاج الشاشة مطلي بطبقة من الفسفور. القاعدة الفيزيائية: لما بتصطدم الإلكترونات بالفسفور، بيشع ضوء مرئي!

"When electrons strike the phosphor coating on the tube, light is emitted."

6. أجهزة الإدخال (Input Devices)

معظم أنظمة الجرافيكس بتوفر لوحة مفاتيح (Keyboard) وجهاز إدخال إضافي واحد على الأقل.
الوظيفة الأساسية لأجهزة الإدخال الرسومية: تمكين المستخدم من تحديد موقع معين على الشاشة (Allow a user to indicate a particular location on the display).
أشهر 4 أجهزة إدخال مذكورة في السلايدات:
1. Mouse (الفأرة).
2. Joystick (عصا التحكم).
3. Data tablet (اللوح الرقمي / قلم الرسم).
4. Trackball (كرة التعقب).

Part 2: Core Concepts Summary (English Reference)

1. Architecture of a Graphics System (6 Major Components):

1. Input Devices (Mouse, joystick, data tablet, trackball, keyboard) • 2. Central Processing Unit (CPU) • 3. Graphics Processing Unit (GPU) • 4. Memory • 5. Frame Buffer • 6. Output Devices (Monitors / CRTs).

2. Pixels, Raster, and Frame Buffer Depth:
  • Raster: The 2D array grid of picture elements (pixels / pels).
  • Frame Buffer: Dedicated portion of memory holding pixel values.
  • Pixel Depth (Precision): Number of bits (n) allocated per pixel. Colors = 2n: 1-bit = 2 (Bitmap), 4-bits = 16, 8-bits = 256, 15-bits = 32,768, 16-bits = 65,536, 24-bits = 16,777,216 (Full-color systems).
  • CRT Mechanics: DACs convert digital pixel values to analog deflection voltages (X, Y plates); electrons strike phosphor coating to emit light.

أسئلة الجزء الثاني (Practice Questions - Part 2 • كويز تفاعلي بالعامية)

الجزء الثالث (Part 3): تكوين الصورة ونموذج الكاميرا الافتراضية (Image Formation & The Pinhole Camera)

1. الصور: الحقيقية مقابل التخليقية (Images: Physical and Synthetic)

في أنظمة الجرافيكس الحديثة، إحنا مش بس بنرسم خطوط 2D؛ إحنا بنستغل إمكانيات السوفت وير والهاردوير عشان نعمل:

"Realistic images of computer-generated three dimensional objects."

عشان تعمل صورة 3D شكلها حقيقي، لازم تفهم وتحاكي العوامل الفيزيائية لتكوين الصورة في الطبيعة:

1. الإضاءة (Lighting).
2. التظليل وتوزيع الظلال (Shading).
3. خصائص ملمس المواد (Properties of materials).

2. الكائنات والناظر (Objects and Viewers)

مبدأ أساسي في السلايدات:

"Two basic entities must be part of any image-formation process: Object and Viewer."

توضيح: عشان تتكون أي صورة في الكون أو في الكمبيوتر، لازم يكون فيه حاجتين أساسيتين:

1. الكائن (The Object): الشيء اللي بنرسمه.
2. الناظر / الكاميرا (The Viewer): الشخص أو الكاميرا اللي بتبص على الكائن ده.
إزاي بنبني الكائن (Object) جوة الكمبيوتر؟

بنبنيه عن طريق تحديد مواضع بدائيات هندسية (Geometric primitives) في الفضاء ثلاثي الأبعاد:

• النقاط (Points).
• الخطوط (Lines).
• المضلعات كالمثلثات والمربعات (Polygons).
مين اللي بيحدد شكل الصورة النهائية؟

"It is the viewer that forms the image of our objects."

الناظر هو اللي بيشكل الصورة! لو عندك نفس الكوباية، وبصيت عليها من فوق هتشوف دايرة، لو بصيت عليها من الجنب هتشوف مستطيل! الكائن ماتغيرش، بس موضع الناظر هو اللي غير الصورة بالكامل.

3. الضوء وتكوين الصورة (Light and Images)

لو عندك كائن (Object) وكاميرا (Viewer) بس في أوضة كحل مفيهاش نور، هتشوف إيه؟ ولا حاجة!

"If there is no light source, the objects would be dark, and there would be nothing visible in our image."

1. إزاي اللون بيدخل الصورة (How color enters the picture).
2. تأثير خصائص أسطح الأجسام على الضوء الساقط (Effects of the surface properties of the objects): هل السطح بيلمع زي المراية ويعكس الضوء؟ ولا خشن زي القماش ويمتصه؟
ما هو الضوء المرئي؟ (Visible Light Spectrum)

الضوء جزء من الطيف الكهرومغناطيسي (Electromagnetic spectrum). طول موجة الضوء المرئي اللي عيوننا بتقدر تشوفه محصور بين:

350 nm   to   780 nm

(nanometers - نانوميتر). دي بتيجي في أسئلة أكمل واختيارات كتير!

4. أنظمة التصوير: كاميرا الثقب (The Pinhole Camera)

عشان نفهم الكاميرات الرقمية وإزاي الكمبيوتر بيسقط الأبعاد التلاتة على شاشة مسطحة (2D)، بنبدأ بأبسط نموذج بصري فيزيائي: كاميرا الثقب (Pinhole Camera).

رسم توضيحي لكاميرا الثقب (Pinhole Camera) وانقلاب الصورة على مستوي الفيلم:
تركيب كاميرا الثقب وإزاي الصورة بتتكون:
1. عبارة عن صندوق مقفول تماماً وفي نصه ثقب صغير جداً (Pin-sized hole) بدون أي عدسة زجاجية.
2. في الجانب المقابل تماماً للثقب بنحط مستوي الفيلم أو الحساس (Film plane).
3. المسافة العمودية بين الثقب ومستوي الفيلم بنسميها البعد البؤري (d) أو Focal Length.
4. أشعة الضوء بتعدي من خلال الثقب في خطوط مستقيمة وتتقاطع، فالنتيجة الحتمية إن الصورة المتكونة على الفيلم بتكون صورة مقلوبة رأساً على عقب (Inverted Image).

5. مواصفات الكاميرا الأربعة (Camera Specifications)

لو طلب منك في الكود أو في الامتحان تحدد كاميرا افتراضية (Virtual / Synthetic Camera) لتصوير المشهد، إيه الخصائص الأربعة الضرورية اللي لازم تحددهم؟

1. الموضع (Position): مكان الكاميرا فين في الفراغ ثلاثي الأبعاد (x, y, z).
2. الاتجاه (Orientation): الكاميرا بتبص فين؟ وزاوية ميلها ودورانها إيه (Up vector وزاوية التوجيه).
3. البعد البؤري (Focal length - d): المسافة بين مركز الإسقاط (الثقب/عدسة الكاميرا) ومستوي الصورة.
4. مستوي الفيلم (Film plane): حجم وأبعاد مستطيل الفيلم أو المستشعر اللي هتسقط عليه الصورة.

Part 3: Core Concepts Summary (English Reference)

  • Synthetic 3D Image Formation: Requires simulating Lighting, Shading, and Properties of materials.
  • Two Fundamental Entities: Every image-formation process requires an Object (built from geometric primitives: points, lines, polygons) and a Viewer (which forms the projected 2D image).
  • Visible Light Spectrum: Electromagnetic waves between 350 nm and 780 nm. Without a light source, objects appear completely dark.
  • Pinhole Camera Model: Enclosed box with a tiny pinhole aperture and an opposite film plane at distance d (focal length). Projects an inverted image.
  • Four Camera Specifications: 1. Position • 2. Orientation • 3. Focal length (d) • 4. Film plane.

أسئلة الجزء الثالث (Practice Questions - Part 3 • كويز تفاعلي بالعامية)

الجزء الرابع (Part 4): النظام البصري البشري وواجهة البرمجة الرسومية (Human Visual System & Graphics API)

1. النظام البصري البشري (The Human Visual System - HVS)

ربط عبقري في السلايد بين الكاميرا وعين الإنسان:

"Our extremely complex visual system has all the components of a physical imaging system, such as a camera or a microscope."

توضيح: عينك مش حاجة غريبة عن التكنولوجيا؛ عينك فيها نفس الأجزاء الفيزيائية بالظبط اللي موجودة في الكاميرا أو الميكروسكوب:

مسار الضوء داخل عين الإنسان وما يناظره في الكاميرا:
1. القرنية والعدسة (Cornea & Lens): الضوء بيدخل العين عن طريق القرنية والعدسة عشان ينكسر ويتركز.
2. القزحية (The Iris): بتفتح وتقفل (زي فتحة العدسة Aperture في الكاميرا) عشان تتحكم في كمية الضوء اللي داخلة للعين.
3. الشبكية (The Retina): عبارة عن سطح ثنائي الأبعاد (2D structure) موجود في قاع وخلفية العين. العدسة بتسقط الصورة المجمعة مباشرة على الشبكية (زي مستوي الفيلم الحساس Film plane في الكاميرا بالظبط).

2. مستقبلات الضوء على الشبكية: الـ Rods والـ Cones (مقارنة الامتحان الشهيرة!)

على سطح الشبكية، ربنا خلق نوعين من الحساسات الضوئية (Light sensors). حجم وكثافة الحساسات دي هو اللي بيحدد دقة الرؤية (Resolution) للعين:

وجه المقارنة الخلايا العصوية (Rods) الخلايا المخروطية (Cones)
مستوى الإضاءة تعمل في الإضاءة المنخفضة والليلية (Low light levels) تعمل في الإضاءة العالية والنهارية (Higher light levels)
المصطلح العلمي للرؤية Scotopic vision Photopic vision
رؤية الألوان لا ترى الألوان (ترى تدرجات الأبيض والأسود والرمادي فقط) مسؤولة عن رؤية الألوان بجميع درجاتها (Color perception)
الدقة والتفاصيل دقة منخفضة (حساسة للحركة والضوء الخافت) مسؤولة عن التفاصيل الدقيقة والحدة (Sharpness)
مثال للتوضيح: لو قفلت النور فجأة في أوضتك، أول ثواني مش هتشوف ألوان وهتشوف كل حاجة رمادية؛ لأن الـ Cones بتفصل في العتمة، ومين اللي بيشتغل وينقذك؟ الـ Rods بنظام الـ Scotopic vision.

3. واجهة المبرمج وواجهة برمجة التطبيقات (The Programmer's Interface & Graphics API)

السلايدات بتفرق بين مستويين للتعامل مع الجرافيكس:

1. المستخدم العادي (End-User): زي اللي بيفتح برنامج رسم (Painting program). بيشوف قوائم وأيقونات، ويدوس بالماوس عشان يرسم من غير ما يكتب سطر كود واحد (Produces images without having to write programs).
2. المبرمج (The Programmer): بيتعامل مع النظام عن طريق كود ومكتبات برمجية.
تعريف الـ API في السلايد:

"The interface between an application program and a graphics system can be specified through a set of functions that resides in a graphics library. These specifications are called the Application Programming Interface (API)."

توضيح: الـ API عبارة عن مجموعة دوال (Functions) جاهزة ومكتوبة جوة مكتبة جرافيكس (زي OpenGL أو DirectX). المبرمج بينادي الدوال دي في الكود بتاعه عشان يقول لكارت الشاشة يعمل اللي هو عاوزه من غير ما يوجع دماغه بتفاصيل الهاردوير الكهربائية المعقدة.

4. واجهات البرمجة ثلاثية الأبعاد (3D APIs & Synthetic-Camera Model)

لو المكتبة الرسومية شغالة بنموذج الكاميرا التخليقية ثلاثية الأبعاد (Synthetic-Camera Model)، لازم الـ API يوفر للمبرمج دوال تتحكم في 4 عناصر رئيسية:

1. الكائنات (Objects): دوال لتحديد إحداثيات النقاط والمجسمات في الـ 3D space.
2. الناظر (A Viewer): دوال لتحديد مكان الكاميرا وزاوية النظر واتجاه الرؤية.
3. مصادر الضوء (Light Sources): دوال لوضع كشافات النور وتحديد ألوانها وشدتها.
4. خصائص المواد (Material Properties): دوال لتحديد هل السطح بيلمع (Specular)، خشن (Diffuse)، ولا شفاف (Transparent).

Part 4: Core Concepts Summary (English Reference)

  • Human Visual System (HVS): Cornea & Lens focus light • Iris regulates amount of light • Retina is the 2D back surface where images form (like the camera's film plane).
  • Retinal Sensors: Rods operate in low light (Scotopic vision, monochrome/no color) • Cones operate in bright light (Photopic vision, responsible for color perception and sharp detail).
  • Application Programming Interface (API): A set of functions residing in a graphics library specifying the interface between an application program and the graphics system.
  • 3D Graphics API (Synthetic-Camera Model) Requirements: Functions to specify 1. Objects • 2. A Viewer • 3. Light sources • 4. Material properties.
