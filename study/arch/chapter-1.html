1. المعمارية مقابل التنظيم (Architecture vs Organization)

1

Computer Architecture vs Computer Organization

1. English (نص السلايدز)

• Computer Architecture: refers to those attributes of a system visible to a programmer, or those attributes that have a direct impact on the logical execution of a program.

• Computer Organization: refers to the operational units and their interconnections that realize the architectural specifications.

• Organizational attributes include those hardware details transparent to the programmer, such as control signals, interfaces between the computer and peripherals, and the memory technology used.

2. الترجمة

الترجمة: العمارة بتشير للخصائص اللي المبرمج بيشوفها في النظام، أو اللي ليها تأثير مباشر على تنفيذ البرنامج منطقيًا.

الترجمة: التنظيم بيشير لوحدات التشغيل ووصلاتها اللي بتحقق المواصفات المعمارية.

الترجمة: الخصائص التنظيمية بتشمل تفاصيل الهاردوير اللي مش ظاهرة للمبرمج، زي إشارات التحكم، الواجهات بين الكمبيوتر والملحقات، وتكنولوجيا الذاكرة.

3. الشرح بالعامية

بالعامية: يعني أي حاجة أنت كمبرمج "بتحس بيها" أو "بتأثر عليك" وأنت بتكتب برنامجك — زي هل فيه تعليمة ضرب ولا لأ، عدد البتات المستخدمة، إلخ.

بالعامية: ده الجزء اللي بيحصل "من تحت الطاولة"، إزاي الحاجة دي بالظبط بتتنفذ جوه الهاردوير من غير ما المبرمج يشوفها أو يهتم بيها.

بالعامية: يعني نوع الذاكرة (RAM) اللي بتستخدمها الشركة، أو إزاي الكارت بيتوصل بالكمبيوتر، ده كله تفاصيل مش شغلانتك كمبرمج، وده اللي يفرقها عن الـ Architecture.

4. الزتونة 🫒
Architecture = "إيه اللي شايفه المبرمج"، Organization = "إزاي اتعمل من جوه في الهاردوير".
5. الخلاصة ✅
Exam ruleأي سؤال عن "حاجة بتأثر على تنفيذ البرنامج / يشوفها المبرمج" ← Architecture. أي سؤال عن "تفاصيل هاردوير مخفية" (إشارات، واجهات، ذاكرة) ← Organization.

2. الوظيفة مقابل البنية (Function vs Structure)

2

Function vs Structure + الوظائف والمكونات الأربع

1. English (نص السلايدز)

• Function: The operation of each individual component as part of the architecture.

• Structure: The way in which the components are interrelated.

• There are 4 basic functions: Data processing.

• Data storage.

• Data movement.

• Control.

• Central Processing Unit (CPU): Controls the operation of the computer and performs its data processing function. It's the portion of a computer that fetches and executes instructions. Often simply referred to as a processor.

• Main memory: stores data.

• I/O: moves data between the computer and its external environment.

• System interconnections: Some mechanism that provides for communication among CPU, main memory, and I/O.

2. الترجمة

الترجمة: الوظيفة هي تشغيل كل مكون فردي كجزء من العمارة.

الترجمة: البنية هي الطريقة اللي بيها المكونات مرتبطة ببعض.

الترجمة: معالجة البيانات.

الترجمة: تخزين البيانات.

الترجمة: نقل البيانات.

الترجمة: التحكم.

الترجمة: وحدة المعالجة المركزية بتتحكم في تشغيل الكمبيوتر وبتقوم بوظيفة معالجة البيانات. هي الجزء اللي بيجيب وينفذ التعليمات، وبتتسمى غالبًا "المعالج".

الترجمة: الذاكرة الرئيسية بتخزن البيانات.

الترجمة: الإدخال/الإخراج بينقل البيانات بين الكمبيوتر وبيئته الخارجية.

الترجمة: وصلات النظام هي آلية بتوفر التواصل بين الـ CPU والذاكرة والـ I/O.

3. الشرح بالعامية

بالعامية: يعني "إيه اللي المكون ده بيعمله فعليًا" — زي الشيف بيطبخ.

بالعامية: يعني "مين متوصل بمين" جوه الجهاز، زي خريطة توصيل المطبخ بالمخزن والجرسون.

بالعامية: أي عملية حسابية أو منطقية بتتعمل على البيانات، زي الجمع أو المقارنة.

بالعامية: حفظ البيانات في مكان (زي الرام أو الهارد) عشان تستخدمها لاحقًا.

بالعامية: تحريك البيانات من جهاز لجهاز، زي من الكيبورد للـ CPU.

بالعامية: توجيه العمليات التانية وتنظيم توقيتها وترتيبها.

بالعامية: هي "المخ" اللي بيدير كل حاجة في الجهاز وبيقرر يعمل إيه بالظبط في كل خطوة.

بالعامية: زي التلاجة اللي حافظة فيها كل البيانات اللي الجهاز محتاجها وهو شغال.

بالعامية: أي حاجة بتوصل الجهاز بالعالم برا، زي الشاشة والكيبورد والطابعة.

بالعامية: الأسلاك أو الباصات اللي بتربط المخ بالتلاجة والباب الخارجي ببعض، من غيرها مفيش حاجة هتتواصل.

4. الزتونة 🫒
ماتلخبطش بين "Storage" (حفظ) و"Movement" (نقل) — التخزين جوه الجهاز، النقل بين الجهاز والخارج أو بين مكونات مختلفة.
5. الخلاصة ✅
Exam ruleالحاسب بيعمل 4 وظائف (Processing, Storage, Movement, Control) عن طريق 4 مكونات (CPU, Main memory, I/O, System interconnections).

3. المكونات البنيوية الكبرى للـ CPU

3

CPU's Major Structural Components

1. English (نص السلايدز)

• CPU: the portion of a computer that fetches and executes instructions. It's often simply referred to as a processor.

• Control unit → controls the operation of the CPU and hence the computer.

• Arithmetic and Logic Unit (ALU) → performs the computer's data processing functions.

• Registers → Provides storage internal to the CPU.

• CPU interconnections → Some mechanism that provides for communication among the control unit, ALU, and registers.

2. الترجمة

الترجمة: الـ CPU هو الجزء من الكمبيوتر اللي بيجيب وينفذ التعليمات، وبيتسمى غالبًا "المعالج".

الترجمة: وحدة التحكم بتدير تشغيل الـ CPU وبالتالي الكمبيوتر كله.

الترجمة: وحدة الحساب والمنطق بتنفذ وظائف معالجة البيانات في الكمبيوتر.

الترجمة: السجلات بتوفر تخزين داخلي جوه الـ CPU.

الترجمة: وصلات الـ CPU آلية بتوفر التواصل بين وحدة التحكم، الـ ALU، والسجلات.

3. الشرح بالعامية

بالعامية: هو اللي بياخد الأوامر وينفذها فعليًا، زي المدير التنفيذي في الشركة.

بالعامية: هي اللي بتقول لكل جزء "دلوقتي اعمل كذا" وبتنظم توقيت كل خطوة.

بالعامية: هي اللي بتعمل العمليات الحسابية والمنطقية فعليًا (جمع، طرح، مقارنة) — الشغل الفعلي.

بالعامية: رفوف صغيرة وسريعة جدًا جوه الـ CPU نفسه، بيحط عليها البيانات اللي محتاجها فورًا، أسرع بكتير من الرام.

بالعامية: الأسلاك الداخلية اللي بتربط التلات مكونات دول ببعض جوه الـ CPU نفسه.

4. الزتونة 🫒
سؤال شائع: "Data processing inside the CPU is performed by...؟" الإجابة: ALU مش Control unit.
5. الخلاصة ✅
Exam ruleCPU = وحدة تحكم Control unit (يوجّه) + وحدة حساب ومنطق ALU (ينفذ) + سجلات Registers (تخزين سريع) + وصلات CPU interconnections (الربط بينهم).

4. معمارية طقم التعليمات (ISA)

4

Instruction Set Architecture (ISA)

1. English (نص السلايدز)

• It defines instruction formats, instruction opcodes, registers, instruction and data memory.

• It defines the effect of executed instructions on the registers and memory.

• It defines an algorithm for controlling instruction execution.

• When data are moved over longer distances, or to/from a remote device, the process is known as data communication.

2. الترجمة

الترجمة: بيحدد صيغ التعليمات، أكواد العمليات، السجلات، وذاكرة التعليمات والبيانات.

الترجمة: بيحدد تأثير التعليمات المنفذة على السجلات والذاكرة.

الترجمة: بيحدد خوارزمية للتحكم في تنفيذ التعليمات.

الترجمة: لما البيانات بتتحرك لمسافات طويلة، أو من/لجهاز بعيد، العملية دي بتتسمى اتصال بيانات.

3. الشرح بالعامية

بالعامية: هو اللي بيحدد "شكل" كل أمر بيتكتب إزاي عشان الـ CPU يفهمه.

بالعامية: يعني لما ينفذ أمر معين، الـ ISA بيحدد إيه اللي هيتغير بالظبط في السجلات أو الذاكرة.

بالعامية: بيحدد الترتيب والخطوات اللي بيها كل تعليمة بتتنفذ.

بالعامية: زي لما بتبعت ملف لصاحبك في بلد تانية — دي "Data communication" مش مجرد "Data movement" عادي جوه الجهاز.

4. الزتونة 🫒
الـ ISA هي "الواجهة" بين الهاردوير والسوفتوير — هي اللي فاصلة بين اللي المبرمج شايفه واللي الهاردوير بينفذه.
5. الخلاصة ✅
Exam ruleISA = القواعد اللي بتحدد شكل التعليمات وتأثيرها، وهي جزء أساسي من تعريف الـ Architecture.

5. وحدات CPU الإضافية (التفاصيل المتقدمة)

5

CPU Additional Units (Advanced Structural Details)

1. English (نص السلايدز)

• Instruction logic: This includes the tasks involved in fetching instructions, and decoding each instruction to determine the instruction operation and the memory locations of any operands.

• Load/store logic: Manages the transfer of data to and from main memory via cache.

• FXU (Fixed-point unit): It executes fixed-point arithmetic operations.

• BFU (Binary floating-point unit): Handles all binary and hexadecimal floating-point operations, as well as fixed-point multiplication operations.

• DFU (Decimal floating-point unit): Handles both fixed-point and floating-point operations on numbers stored as decimal digits.

• RU (Recovery unit): Keeps a copy of the complete state of the system that includes all registers, collects hardware fault signals, and manages the hardware recovery actions.

• COP (Dedicated co-processor): The COP is responsible for data and encryption functions for each core.

2. الترجمة

الترجمة: منطق التعليمات بيشمل مهام جلب التعليمات وفك تشفيرها لتحديد نوع العملية وأماكن أي بيانات في الذاكرة.

الترجمة: منطق التحميل/التخزين بيدير نقل البيانات من وإلى الذاكرة الرئيسية عن طريق الكاش.

الترجمة: وحدة النقطة الثابتة بتنفذ عمليات حسابية بالأرقام الصحيحة.

الترجمة: وحدة الفاصلة العائمة الثنائية بتتعامل مع عمليات الفاصلة العائمة الثنائية والست عشرية، وكمان ضرب الأرقام الصحيحة.

الترجمة: وحدة الفاصلة العائمة العشرية بتتعامل مع العمليات الصحيحة والعائمة على أرقام مخزنة كأرقام عشرية.

الترجمة: وحدة الاسترجاع بتحتفظ بنسخة من حالة النظام بالكامل، وبتجمع إشارات الأعطال، وبتدير عمليات استرجاع الهاردوير.

الترجمة: المعالج المساعد المخصص مسؤول عن وظائف البيانات والتشفير لكل نواة.

3. الشرح بالعامية

بالعامية: القسم اللي بيجيب الأمر ويفهمه ويحدد هيتعامل مع أنهي بيانات بالظبط.

بالعامية: القسم المسؤول عن جيب وحفظ البيانات من التلاجة الكبيرة مرورًا بالكاش السريع.

بالعامية: المتخصصة في الأرقام الصحيحة العادية (زي 5، 10، 100).

بالعامية: المتخصصة في الأرقام اللي فيها فاصلة عشرية بالنظام الثنائي، وكمان بتعمل عمليات الضرب.

بالعامية: زي BFU بس متخصصة في الأرقام المخزنة بصيغة عشرية مش ثنائية.

بالعامية: زي "الـ Save point" في اللعبة — لو حصل عطل مفاجئ، هي اللي بترجّع الجهاز لآخر حالة سليمة.

بالعامية: قسم الأمان بتاع كل نواة، مسؤول عن التشفير وحماية البيانات.

4. الزتونة 🫒
الفرق الأساسي بين FXU و BFU و DFU هو "نوع الأرقام" اللي كل وحدة بتتعامل معاها (صحيحة / ثنائية عائمة / عشرية).
5. الخلاصة ✅
Exam ruleدي وحدات متخصصة جوه المعالجات الحديثة، كل واحدة ليها شغلانة محددة تخلي الأداء والموثوقية أعلى (Instruction logic, Load/store logic, FXU, BFU, DFU, RU, COP).

6. النظام المدمج (Embedded System)

6

Embedded System

1. English (نص السلايدز)

• It refers to the use of electronics and software within a product, as opposed to a general-purpose computer, such as a laptop or desktop system.

2. الترجمة

الترجمة: بيشير لاستخدام الإلكترونيات والسوفتوير جوه منتج معين، عكس الكمبيوتر العام الاستخدام زي اللابتوب أو الديسكتوب.

3. الشرح بالعامية

بالعامية: أي جهاز بيقوم بمهمة واحدة أو محدودة زي الغسالة أو الميكروويف — هو "كمبيوتر" لكن مخصص لحاجة واحدة بس مش عام زي اللابتوب.

4. الزتونة 🫒
الكلمة المفتاحية: "as opposed to a general-purpose computer" — يعني أي جهاز مش عام الاستخدام هو Embedded system.
5. الخلاصة ✅
Exam ruleإلكترونيات + سوفتوير مدمجين جوه منتج لأداء وظيفة محددة.

7. إنترنت الأشياء (IoT)

7

The Internet of Things (IoT)

1. English (نص السلايدز)

• Is a term that refers to the expanding interconnection of smart devices, ranging from appliances to tiny sensors.

• The internet has gone through roughly four generations of deployment culminating in the IoT: 1. Information technology (IT), 2. Operation technology (OT), 3. Personal technology, 4. Sensor/actuator technology.

2. الترجمة

الترجمة: مصطلح بيشير للتوسع في ترابط الأجهزة الذكية، من الأجهزة المنزلية لحد أصغر المستشعرات.

الترجمة: الإنترنت مر بأربع أجيال تقريبًا وصلت لـ IoT: تكنولوجيا المعلومات، تكنولوجيا التشغيل، التكنولوجيا الشخصية، تكنولوجيا المستشعرات/المشغلات.

3. الشرح بالعامية

بالعامية: يعني أي حاجة حواليك ممكن "توصّل بالنت" وتتكلم مع بعض — من الثلاجة لحد حساس صغير جدًا في مصنع.

بالعامية: يعني الإنترنت بدأ بأجهزة كبيرة في الشركات (IT)، بعدين مصانع (OT)، بعدين موبايلات وأجهزة شخصية، ودلوقتي وصل لحساسات صغيرة جدًا في كل حاجة.

4. الزتونة 🫒
IoT = ترابط أجهزة ذكية متنوعة (مش بس كمبيوترات وموبايلات).
5. الخلاصة ✅
Exam ruleIoT هو آخر مرحلة من تطور الإنترنت، فيها أي جهاز حتى الصغير جدًا بقى يقدر يتصل بالشبكة.

8. الحوسبة السحابية (Cloud Computing)

8

Cloud Computing

1. English (نص السلايدز)

• A model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.

• Cloud services: A cloud service provider (CSP) maintains computing and data storage resources that are available over the internet or private networks.

• The essential purpose of cloud computing is to provide for the convenient rental of computing resources.

2. الترجمة

الترجمة: نموذج بيتيح وصول سهل ومتاح في أي وقت لمجموعة مشتركة من موارد الحوسبة القابلة للتهيئة (شبكات، سيرفرات، تخزين، تطبيقات، خدمات)، وممكن تتوفر وتتلغي بسرعة وبأقل مجهود إداري.

الترجمة: مزود خدمة الكلاود بيحتفظ بموارد حوسبة وتخزين بيانات متاحة عبر الإنترنت أو شبكات خاصة.

الترجمة: الهدف الأساسي من الكلاود هو توفير إيجار مريح لموارد الحوسبة.

3. الشرح بالعامية

بالعامية: بدل ما تشتري سيرفر وتركبه بنفسك، بتاخد "موارد جاهزة" من شركة عن طريق النت، وتقدر تزود أو تقلل منها في أي وقت بضغطة زرار.

بالعامية: الشركة اللي بتأجرك الموارد دي (زي Amazon أو Google) هي اللي شايلة همّ الصيانة والتشغيل عنك بالكامل.

بالعامية: يعني في الآخر الكلاود هو "تأجير" مش "تمليك" لموارد الحاسب.

4. الزتونة 🫒
الكلمة المفتاحية اللي بتتكرر في الامتحانات: "convenient rental of computing resources".
5. الخلاصة ✅
Exam ruleاستئجار موارد حوسبة عبر الإنترنت من مزود خدمة، بمرونة عالية وأقل مجهود إداري.

1
Architecture vs Organization

أي سؤال عن "حاجة بتأثر على تنفيذ البرنامج / يشوفها المبرمج" ← Architecture. أي سؤال عن "تفاصيل هاردوير مخفية" (إشارات، واجهات، ذاكرة) ← Organization.

2
Function vs Structure
