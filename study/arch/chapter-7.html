أحجام وتنسيقات البيانات

المعالج يسحب بلوك 64-bit على التوازي، والكيبورد يرسل حرفاً بحرف 7-bit.

1. فجوة السرعة الهائلة (Speed Mismatch):

المعالج شغال بمليارات العمليات في الثانية (Gigahertz)، بينما كيبورد بتكتب عليه حرفين في الثانية، أو هارد ديسك بيلف ميكانيكياً. لو المعالج شبك فيهم مباشرة هيفضل "مشلول" مستني أجهزة سلحفائية.

2. اختلاف الإشارات والفيزياء (Operating Principles):

المعالج بيفهم إشارات كهربائية رقمية نقية، بينما الأجهزة الخارجية فيها محركات ميكانيكية، ليزر ضوئي (CD)، مجالات مغناطيسية (Hard Disk)، وموجات راديو (Wi-Fi).

3. تض��رب أحجام البيانات (Data Format & Word Length):

المعالج بينقل كلمات كاملة (32-bit أو 64-bit على التوازي)، بينما كيبورد أو كابل إنترنت بيبعت تيار سيريال متتابع بت ورا بت أو حرف حرف.

1. التحكم والتوقيت (Control & Timing):

تنسيق حركة المرور بين مصادر المعالج الداخلية والأجهزة الخارجية حتى لا يحدث تصادم في الإشارات الكهربائية على الباص.

2. التواصل مع المعالج (Processor Communication):

  • • يفك تشفير أوامر المعالج (Command Decoding) مثل: READ و WRITE و STATUS.
  • • يتعرف على عنوان الجهاز الخاص به (Address Recognition).
  • • يبلغ المعالج بحالته (Status Reporting) مثل: الجهاز مشغول (Busy)، أو جاهز (Ready).

3. التواصل مع الجهاز الخارجي (Device Communication):

يرسل الأوامر المناسبة للطرفية (مثلاً: ابدأ لف أسطوانة الهارد، اسحب ورقة في الطابعة) ويتبادل الداتا معها.

4. تخزين البيانات مؤقتاً (Data Buffering) — أهم وظيفة!

سرعة نقل البيانات بين المعالج والرامة تصل لجيجابايت/ثانية، بينما الجهاز الخارجي بطيء جداً. الـ I/O Module يستقبل البيانات بسرعة من المعالج ويخزنها في مسجلات داخلية (Buffers)، ثم يقطرها بالراحة للجهاز الخارجي حسب سرعته (أو العكس في الإدخال)، وبالتالي يمنع حبس المعالج وتعطيله.

5. كشف الأخطاء (Error Detection):

مراقبة أي خطأ ميكانيكي في الجهاز (مثل: الورق خلص في الطابعة، أو الباد سيكتور في الهارد) أو خطأ كهربائي في نقل الإشارات (باستخدام بتات الـ Parity).

السؤال 7.1 | Question 7.1

Q: List three broad classifications of external, or peripheral, devices.

الترجمة: اذكر التصنيفات الثلاثة الرئيسية للأجهزة الخارجية (الطرفية) المتصلة بالكمبيوتر.

الإجابة النموذجية بالإنجليزية (Model Answer):

External or peripheral devices are broadly classified into three categories based on the entity they communicate with:

  1. Human readable: Suitable for communicating directly with the computer user.
    Examples: Video Display Terminals (VDTs/monitors), keyboards, and printers.
  2. Machine readable: Suitable for communicating with computer equipment and physical systems.
    Examples: Magnetic disk and tape systems, sensors, and actuators.
  3. Communication: Suitable for communicating with remote devices or other computers.
    Examples: Modems and Network Interface Cards (NICs).
الشرح بالبلدي والتركيز للامتحان:

بنقسم الأجهزة حسب مين الطرف التاني اللي بيتكلم معاها: إنسان، ولا ماكينة تانية، ولا شبكة بعيدة. اذكر التصنيف ومثالين عليه عشان تاخد الدرجة كاملة فوراً.

🔑 الكلمات المفتاحية (Keywords للدرجة الكاملة):
Human readable (VDTs, printers, keyboards) Machine readable (magnetic disk/tape, sensors, actuators) Communication (modems, remote devices)
السؤال 7.2 | Question 7.2

Q: What is the International Reference Alphabet (IRA)?

الترجمة: ما هي أبجدية المرجع الدولي (IRA) وما خصائصها؟

الإجابة النموذجية بالإنجليزية (Model Answer):

The International Reference Alphabet (IRA) (commonly known as ASCII) is a standardized character-encoding scheme used for the exchange of data between the computer and human-readable peripherals:

  1. 7-bit Code: Each character is uniquely represented by a 7-bit binary code, allowing a total of 27 = 128 distinct characters.
  2. Character Types:
    • Printable characters: Alphabetic letters, numeric digits, and special punctuation characters that can be displayed or printed.
    • Control characters: Non-printing codes concerned with controlling the printing/display format (e.g., carriage return) or communications procedures.
الشرح بالبلدي والتركيز للامتحان:

هو جدول الأسكي الشهير: كل حرف محجوز له كود 7 بت (128 شكل)، وفيه نوعين: حروف بتظهر على الشاشة (Printable)، وأزرار تحكم وتنظيم وظائف (Control).

🔑 الكلمات المفتاحية (Keywords للدرجة الكاملة):
7-bit binary code (128 different characters) Standardized character encoding Printable characters Control characters
السؤال 7.3 | Question 7.3

Q: What are the major functions of an I/O module?

الترجمة: ما هي الوظائف والمهام الرئيسية لوحدة الإدخال والإخراج (I/O Module)؟

الإجابة النموذجية بالإنجليزية (Model Answer):

The major functions of an I/O module fall into five key categories:

  1. Control and Timing: Coordinates the flow of traffic between internal computer resources (processor, memory) and external peripheral devices.
  2. Processor Communication: Handles command decoding, status reporting, address recognition, and data exchange with the processor.
  3. Device Communication: Exchanges commands, device status information, and data directly with the peripheral device.
  4. Data Buffering: Temporarily stores data in internal registers to bridge and balance the massive speed disparity between high-speed system buses and low-speed peripherals.
  5. Error Detection: Detects and reports mechanical faults (e.g., paper jams) and transmission errors (e.g., bit parity errors).
الشرح بالبلدي والتركيز للامتحان:

الدكتور لما يسألك عن وظائف موديول الـ I/O عاوز الـ 5 رؤوس دول: تحكم وتوقيت، كلام مع المعالج، كلام مع الجهاز، تخزين مؤقت للسرعة (Buffering)، وكشف الأخطاء.

🔑 الكلمات المفتاحية (Keywords للدر��ة الكاملة):
Control and timing Processor communication Device communication Data buffering Error detection

التقنيات الثلاث لتنفيذ الإدخال والإخراج (Three I/O Techniques)

فكرة سؤال الدكتور 7.4

1 الإدخال والإخراج المبرمج (Programmed I/O)

كيف يعمل؟

المعالج يصدر أمر القراءة/الكتابة لـ I/O Module، وبعدها يدخل في حلقة تكرارية مستمرة (Loop) يفضل يسأل فيها مسجل الحالة (Status Register) بتاع الجهاز: "يا جهاز جهزت؟ يا جهاز خلصت؟"، ويفضل واقف مكانه مبيعملش أي حاجة تانية لحد ما الداتا تجهز! العملية دي بنسميها هندسياً: الانتظار النشط أو الفحص الدوري (Busy-Waiting / Polling).

⚠️ العيب القاتل: إهدار مرعب لقوة المعالج الحسابية؛ المعالج السريع جداً بيفضل مشلول ومحبوس في لوب لمجرد انتظار جهاز خارجي بطيء.

2 الإدخال والإخراج المدفوع بالمقاطعة (Interrupt-Driven I/O)

كيف يعمل؟

المعالج يصدر أمر القراءة/الكتابة لـ I/O Module، لكن مش بيقف يستنى نهائياً! المعالج بيكمل شغله الطبيعي وينفذ برامج تانية في الذاكرة. لما الجهاز الخارجي يجهز البيانات في البافر الداخلي بتاعه، موديول الـ I/O يبعت إشارة كهربائية على سلك تحكم خاص بالمعالج اسمها إشارة مقاطعة (Interrupt Signal). المعالج يوقف شغله مؤقتاً، يستقبل البيانات بسرعة، ثم يرجع يكمل شغله القديم.

✅ الميزة: قضينا تماماً على تضييع وقت المعالج في الانتظار (No busy-waiting).
⚠️ العيب المتبقي: المعالج لا يزال هو المسؤول عن نقل كل كلمة داتا بنفسه بين مسجلات الـ I/O والذاكرة (CPU is still tied up in transferring data). لو بننقل ملف كبير (جيجابايت)، المعالج هيتقاطع ملايين المرات وهيختنق في النقل الروتيني.

3 الوصول المباشر للذاكرة (Direct Memory Access - DMA)

كيف يعمل؟

المعالج قرر "يعيّن مدير مالي" مخصوص لنقل البيانات الضخمة اسمه وحدة الـ DMA Controller. المعالج يكتفي بإعطاء أمر أولي لـ DMA: "انقل بلوك من 1024 Words من القطاع رقم 5 في الهارد ووديهم للعنوان 0x5000 في الرامة، ولما تخلص خالص رن عليّ!". وحدة الـ DMA هي اللي بتمسك الباص وتتحكم فيه، وتنقل البلوك بالكامل مباشرة بين جهاز الإدخال/الإخراج والذاكرة الرئيسية دون أي تدخل من المعالج!

🌟 الميزة الكبرى: المعالج متفرغ بنسبة 100% للعمليات الحسابية، ولا يتدخل إلا في البداية لتوجيه الأمر، وفي النهاية لما الـ DMA يبعت له Interrupt يقول له "البلوك كله اتنقل بنجاح".

فكرة سؤال الدكتور 7.6

كيف يعرف المعالج بدقة متناهية أي جهاز بالتحديد هو الذي أرسل المقاطعة وما هو عنوان الكود (ISR) المطلوب لتشغيله؟

1) خطوط مقاطعة متعددة (Multiple Interrupt Lines)

  • • الفكرة: المعالج يخصص له عدة أرجل (Pins) فيزيائية في الشريحة، وكل جهاز يتوصل بسلك مستقل تماماً.
  • • كيف يعرف الجهاز؟ من رقم السلك اللي الفولت فيه ارتفع!
  • • العيوب: محدودة جداً بعدد أرجل المعالج (Pins) المتاحة، فمن المستحيل توصيل عشرات الأجهزة بهذه الطريقة.

2) الاستطلاع البرمجي (Software Poll)

  • • الفكرة: كل الأجهزة تشترك في سلك مقاطعة عام واحد.
  • • كيف يعرف الجهاز؟ أول ما المعالج يستقبل المقاطعة، ينط فوراً لبرنامج عام اسمه (Poll Routine)، ويبدأ يسأل مسجل حالة كل جهاز بالترتيب: "أنت يا كيبورد اللي قاطعت؟ لا.. أنت يا طابعة؟ لا.. أنت يا ماوس؟ أيوه أنا".
  • • العيوب: بطيئة جداً في الاستجابة لأن المعالج يضيع وقتاً في فحص الأجهزة غير المطلوبة.

3) السلسلة المتعاقبة (Daisy Chain - Hardware Poll / Vectored)

  • • الفكرة: ربط الأجهزة وراء بعضها بسلسلة إشارات متتالية بترتيب أولوياتها (Priority Order).
  • • كيف يعرف الجهاز؟ المعالج يرسل إشارة موافقة على المقاطعة تسمى (Interrupt Acknowledge - INTA). تمر هذه الإشارة على الجهاز الأول؛ إن كان هو صاحب المقاطعة يحتجز الإشارة ويضع شفرة خاصة به (Interrupt Vector / ID) على خطوط البيانات مباشرة ليعرف المعالج مكانه فوراً. إن لم يكن هو، يمرر الإشارة للجهاز الذي يليه بالسلسلة.
  • • الميزة: سريعة جداً وهاردوير بحت، وتدمج الأولوية تلقائياً.

4) تحكيم خطوط الباص (Bus Arbitration - Vectored)

  • • الفكرة: الجهاز الذي يريد طلب مقاطعة يجب أن ينافس أولاً للحصول على حق السيطرة على الباص (Bus Master) عبر دائرة تحكيم (Bus Arbiter).
  • • كيف يعرف الجهاز؟ عندما يربح الجهاز السيطرة على الباص، يُصدر إشارة المقاطعة ثم يرسل رقم هويته (Interrupt Vector) على خطوط البيانات فوراً، فيقرؤه المعالج مباشرة دون الحاجة لأي فحص برمجي.

السؤال 7.4 | Question 7.4

Q: List and briefly define three techniques for performing I/O.

الترجمة: اذكر وعرّف باختصار التقنيات الثلاث المستخدمة في تنفيذ عمليات الإدخال والإخراج.

الإجابة النموذجية بالإنجليزية (Model Answer):

The three primary techniques for performing I/O operations are:

  1. Programmed I/O: The processor executes a program that gives it direct control of the I/O operation (including sensing device status, issuing read/write commands, and transferring data). The processor must wait until the I/O operation is complete via busy-waiting (polling), which wastes considerable processor time.
  2. Interrupt-Driven I/O: The processor issues an I/O command and continues executing other instructions. When the I/O module is ready to exchange data, it sends an interrupt signal to the processor. The processor executes the data transfer and then resumes its prior task, eliminating idle waiting.
  3. Direct Memory Access (DMA): A specialized hardware module (DMA Controller) manages the direct transfer of large blocks of data between the I/O module and main memory without continuous processor involvement. The processor is only involved at the beginning (initialization) and at the end (when receiving a completion interrupt).
الشرح بالبلدي والتركيز للامتحان:

التلات طرق هما: البرمجة المباشرة والانتظار (Programmed)، الاستدعاء بالجرس عند الجاهزية (Interrupt)، والاستعانة بمدير ينقل الكتل الضخمة رأساً للذاكرة (DMA).

🔑 الكلمات المفتاحية (Keywords للدرجة الكاملة):
Programmed I/O (busy-waiting / polling) Interrupt-driven I/O (asserts interrupt, eliminates waiting) Direct Memory Access / DMA (direct transfer without processor involvement)
السؤال 7.5 | Question 7.5

Q: What is the difference between memory-mapped I/O and isolated I/O?

الترجمة: ما هو الفرق بين الإدخال والإخراج المعنون بالذاكرة (Memory-Mapped I/O) والإدخال والإخراج المعزول (Isolated I/O)؟

الإجابة النموذجية بالإنجليزية (Model Answer):

The fundamental architectural differences are:

  1. Memory-Mapped I/O:
    • Single Address Space: There is a single, shared address space for both memory locations and I/O devices. The processor treats I/O ports as if they were memory locations.
    • Standard Instructions: The processor uses standard memory-referencing instructions (e.g., LOAD, STORE, MOVE) to perform I/O operations.
    • Address Space Penalty: It consumes part of the memory address space, slightly reducing the maximum memory capacity available for RAM.
  2. Isolated I/O (Port-Mapped I/O):
    • Separate Address Spaces: Main memory and I/O devices have distinct, independent address spaces (an I/O address does not refer to a memory location).
    • Specialized Instructions: The processor must use specialized I/O instructions (e.g., IN, OUT).
    • Control Lines: Requires a separate control line on the system bus (such as an I/O / MEM signal) to indicate whether the address on the address bus refers to a memory location or an I/O port.
الشرح بالبلدي والتركيز للامتحان:

قارن بينهما من حي��: مساحة العناوين (واحدة مشتركة ولا منفصلتين؟)، ونوع التعليمات (LOAD/STORE ولا IN/OUT؟)، والتأثير على سعة الرامات.

🔑 الكلمات المفتاحية (Keywords للدرجة الكاملة):
Memory-Mapped I/O (single/shared address space, standard memory instructions) Isolated I/O (separate address spaces, dedicated IN/OUT instructions)
السؤال 7.6 | Question 7.6

Q: When a device interrupt occurs, how does the processor determine which device issued the interrupt?

الترجمة: عندما تحدث مقاطعة من جهاز ما، كيف يحدد المعالج أي الأجهزة بالتحديد هو الذي أصدر تلك المقاطعة؟

الإجابة النموذجية بالإنجليزية (Model Answer):

The processor identifies the interrupting device using one of four general schemes:

  1. Multiple Interrupt Lines: The processor provides dedicated, physical interrupt request lines for individual devices. The line that is asserted immediately identifies the specific interrupting device (limited by processor pin count).
  2. Software Poll: The processor branches to a general interrupt service routine that polls each I/O module in sequence by reading its status register until it identifies the device requesting service (simple hardware, but slow).
  3. Daisy Chain (Hardware Poll / Vectored Interrupt): The processor asserts an interrupt acknowledge signal (INTA) that ripples sequentially through I/O modules connected in priority order. The requesting module intercepts the signal and places its unique identification code or vector (Interrupt Vector) on the data bus.
  4. Bus Arbitration (Vectored Interrupt): An I/O module must first request and be granted control of the system bus through a hardware bus arbiter before asserting the interrupt line; it then directly places its interrupt vector on the bus.
الشرح بالبلدي والتركيز للامتحان:

المعالج بيعرف الجهاز بـ 4 طرق: سلكة مستقلة لكل جهاز (Multiple Lines)، لفة برمجية يسألهم واحد واحد (Software Poll)، تمرير إشارة موافقة بسلسلة هاردوير واللي طلب يحط رقمه (Daisy Chain)، أو الفوز بالباص أولاً ووضع رقم المقاطعة (Bus Arbitration).

🔑 الكلمات المفتاحية (Keywords للدرجة الكاملة):
Multiple interrupt lines Software poll Daisy chain (INTA ripples, Interrupt Vector) Bus arbitration

Q 7.3: What are the major functions of an I/O module? Q 7.3
الإنجليزي للامتحان (أقصر إجابة):
  1. Control and Timing: Coordinates traffic between CPU and devices.
  2. Processor Communication: Decodes commands, reports status, and recognizes addresses.
  3. Device Communication: Sends control signals and data to peripherals.
  4. Data Buffering: Bridges speed differences between fast bus and slow devices.
  5. Error Detection: Detects transmission and device mechanical errors.
💡 الشرح بالبلدي في سطر:

موديول الـ I/O هو المترجم اللي بيظبط المواعيد، يترجم أوامر المعالج، يكلم الجهاز الخارجي، يخزن الداتا مؤقتاً عشان يوازن السرعات، ويكشف أي عطل.

Q 7.4: List and briefly define three techniques for performing I/O. Q 7.4
الإنجليزي للامتحان (أقصر إجابة):
  1. Programmed I/O: CPU directly controls transfer and wastes time in busy-waiting (polling).
  2. Interrupt-Driven I/O: CPU issues command and continues working; I/O module sends an interrupt signal when ready.
  3. Direct Memory Access (DMA): Dedicated controller transfers data blocks directly to/from memory without CPU intervention.
💡 الشرح بالبلدي في سطر:
  • • Programmed: المعالج بيفضل واقف ومحبوس يسأل الجهاز "خلصت ولا لسه؟".
  • • Interrupt: المعالج يرمي الأمر ويشوف شغله، والجهاز يرن عليه جرس أول ما يجهز.
  • • DMA: مدير مخصوص بينقل الداتا للرامة مباشرة والمعالج ملوش أي دعوة.
Q 7.5: What is the difference between memory-mapped I/O and isolated I/O? Q 7.5
الإنجليزي للامتحان (أقصر إجابة):
  • Memory-Mapped I/O: Single shared address space; uses standard memory instructions (LOAD/STORE); reduces available RAM space.
  • Isolated I/O: Separate address spaces; uses dedicated I/O instructions (IN/OUT); preserves full RAM space.
💡 الشرح بالبلدي في سطر:
  • • Memory-Mapped: المنافذ واخدة عناوين جوة الرامة وبنستخدم نفس أوامر الذاكرة بس بتاكل من مساحة الرامة.
  • • Isolated: المنافذ ليها شوارع وعناوين لوحدها برة الرامة ومحتاجة أوامر خاصة زي (IN/OUT).
Q 7.6: When a device interrupt occurs, how does the processor determine which device issued it? Q 7.6
الإنجليزي للامتحان (أقصر إجابة):
  1. Multiple Lines: Dedicated physical interrupt line for each device.
  2. Software Poll: CPU polls each device's status register sequentially.
  3. Daisy Chain (Hardware Poll): Acknowledge signal cascades through devices; requesting device sends its vector.
  4. Bus Arbitration: Device must win bus control first, then asserts its vector.

المعالج بيعرف مين صاحب المقاطعة بـ 4 طرق: يا سلكة مستقلة لكل جهاز، يا يلف يسألهم بالسوفتوير واحد واحد، يا سلسلة هاردوير (Daisy Chain) واللي طلب يرمي بطاقته، يا الجهاز يكسب الباص الأول ويبعت رقم المقاطعة.
