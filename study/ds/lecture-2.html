يعني إيه عقدة (Node)؟

في الـ Linked List مبنقولش عليه متغير عادي، بنسميه عقدة (Node)، وهي علبة مقسومة من جوة لـ جيبين:

📦 تشريح علبة العقدة (Node) من الداخل — مقسومة إلى جيبين:
Data Field
(1. جيب الداتا)
بيشيل القيمة الفعلية: 10، 20...
Link / Next Pointer
(2. جيب العنوان / المؤشر)
بيشيل عنوان العقدة اللي جاية بعدنا في الـ RAM

1. جيب الداتا (Data Field): بنحط فيه القيمة اللي تهمنا (رقم الطالب، السن، الدرجة...).

2. جيب الرابط (Link / Next Pointer): ده مؤشر بنسجل فيه عنوان العقدة اللي جاية بعدنا في الـ RAM.

3

تشريح كود بناء الـ Node في C++ كلمة كلمة

C++ — struct Node 
struct Node {
    int data;
    Node* next;
};

• كلمة struct: بتسمح لك تصنع نوع بيانات جديد على مزاجك يجمع كذا متغير جواه (رقم صحيح + عنوان في الذاكرة).

• كلمة Node: الاسم اللي اخترناه للعلبة الجديدة، وبقى نوع بيانات رسمي في برنامجنا.

• السطر int data;: الجيب الأول لحجز مكان لرقم صحيح داخل العقدة.

• السطر Node* next; (أهم سطر في القصة كلها ⭐): علامة النجمة * معناها إنه مؤشر (Pointer) بيشيل عنوان مكان في الـ RAM، ونوعه Node لأنه بيشاور على عقدة تانية كاملة شبهه بالظبط!

🎓 في الامتحانات بيسموه: Self-Referential Structure (هيكل بيحتوي جواه على مؤشر بيشاور على هيكل من نفس نوعه).

كود إنشاء وربط 3 عقد بالتفصيل الممل والخطوات

main.cpp — Creating & Linking 3 Nodes 
#include <iostream>
using namespace std;

// 1. تعريف قالب العقدة
struct Node {
    int data;
    Node* next;
};

int main() {
    // 2. مؤشر البداية يبدأ فاضي
    Node* head = NULL;

    // 3. حجز 3 عقد منفصلين في الـ Heap
    Node* first  = new Node();
    Node* second = new Node();
    Node* third  = new Node();

    // 4. وضع الداتا وربط الأولى بالتانية
    first->data = 10;
    first->next = second; // دي الرابطة الأولى!

    // 5. وضع الداتا وربط التانية بالتالتة
    second->data = 20;
    second->next = third; // دي الرابطة التانية!

    // 6. وضع الداتا وقفل العقدة التالتة
    third->data = 30;
    third->next = NULL;   // مفيش بعدها حد

    // 7. توجيه مؤشر البداية head
    head = first;

    return 0;
}

روح طبّق الآن بإيدك (Hands-on) + ملخص وأسئلة الجزء الأول

solution.cpp — Hands-on Practice Solution 
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

int main() {
    Node* n1 = new Node();
    Node* n2 = new Node();

    n1->data = 50;
    n2->data = 100;

    n1->next = n2;   // n1 مسكت في إيد n2
    n2->next = NULL; // n2 هي الأخيرة

    Node* head = n1;

    cout << "First value: " << head->data << endl;         // طبع 50
    cout << "Second value via head: " << head->next->data << endl; // طبع 100

    return 0;
}

ملخص الامتحان والمراجعة السريعة (Notebook & Exam Cheatsheet)

[خاص بالمحاضرة الثانية: أساسيات الـ Linked List]
1. CORE DEFINITIONS (تعريفات الامتحان الأكاديمية):
Linked List:
▪Definition: A linear data structure where elements are not stored at contiguous
memory locations. Elements are linked using pointers.
▪بالعامية: هيكل بيانات خطي عناصره مش متلاصقة في الذاكرة، وبتتربط ببعض بمؤشرات.
Node:
▪Definition: The basic building block of a linked list, containing a data field
and a link/pointer field to the next node.
▪بالعامية: العلبة الأساسية في القائمة، مقسومة جيب للداتا وجيب لعنوان العقدة اللي بعدها.
Head Pointer:
▪Definition: A pointer variable storing the memory address of the first node.
If the list is empty, Head points to NULL.
▪بالعامية: مؤشر بيشيل عنوان أول عقدة في القائمة، وبيكون NULL لو القائمة فاضية.
Self-Referential Structure:
▪Definition: A structure containing a pointer pointing to a structure of the same type.
▪بالعامية: استركشر جواه مؤشر بيشاور على استركشر من نفس نوعه (Node* next جوة struct Node).
2. COMPARISON TABLE: ARRAY vs. LINKED LIST (مقارنة الامتحان):
Feature (المقارنة)Array (المصفوفة)Linked List (القائمة المتصلة)
Memory AllocationContiguous (متصلة إجبارياً)Non-contiguous (متفرقة بالذاكرة)
SizeFixed / Static sizeDynamic (تنمو وتنكمش بحرية)
Insertion at BeginningO(n) [Needs Shifting]O(1) [Fast pointer update]
Access by IndexO(1) [Direct calculation]O(n) [Sequential traversal]
Memory OverheadNoneExtra space for pointers (next)
3. EXAM RULES & OPERATORS (قواعد الأكواد والامتحانات):
▪الرمز (*) في السطر Node* p; -> معناه إن p مؤشر بيشيل عنوان مكان في الذاكرة.
▪علامة السهم (->): p->data -> معناها روح للمكان في الذاكرة وافتح جيب الداتا.
▪الرابطة first->next = second; -> معناها خزن عنوان العقدة second جوة مؤشر first.
▪القيمة NULL في العقدة الأخيرة -> معناها دي نهاية القائمة (End of List).
▪فحص القائمة الفاضية -> بيتعمل بالشرط: if (head == NULL).

Q1: What does a "Self-Referential Structure" mean in the context of Linked Lists?
A) A structure that calls its own member functions recursively.
✅ B) A structure containing a pointer to a structure of the same type.
C) A structure that allocates its own memory automatically without new.
D) An array that resizes itself dynamically during program runtime.
💡 Correct Answer: B
التفسير: الهيكل المرجعي الذاتي معناه إن الـ struct يحتوي جواه على مؤشر بيشاور على هيكل من نفس نوعه، زي وجود Node* next جوة struct Node.
Q2: In the line `first->next = second;`, what actually happens in physical memory?
A) The value of second is copied into first.
✅ B) The memory address of second is stored inside the next pointer of first.
C) The second node is deleted from the heap.
D) Both first and second are merged into a single array.
💡 Correct Answer: B
التفسير: السطر ده معناه تخزين عنوان العقدة second في الـ RAM جوة مؤشر next بتاع العقدة first، وده اللي بيخلق الرابطة بينهم.
Q3: What is the main advantage of a Linked List over a standard Array?
A) Faster access to elements via direct index calculation.
B) Lower total memory consumption because it uses no pointers.
✅ C) Dynamic size and efficient insertions/deletions without element shifting.
D) Automatic compilation to hardware registers.
💡 Correct Answer: C
التفسير: الميزة الأساسية هي الحجم الديناميكي، وإننا بنقدر نضيف ونمسح بدون ما نعمل إزاحة (Shift) للعناصر زي ما بيحصل في المصفوفة.
Q4: What is the time complexity to access an element at index k in a linked list?
A) O(1)
✅ B) O(n)
C) O(log n)
D) O(n^2)
💡 Correct Answer: B
التفسير: اللينكد ليست معندهاش إندكس مباشر؛ عشان توصل للعنصر رقم k لازم تبدأ من الـ head وتلف ورا الأسهم خطوة بخطوة، وده بياخد وقت O(n).

#include <iostream>
using namespace std;

// 1. تعريف العقدة
struct Node {
    int data;
    Node* next;
};

// 2. دالة الإضافة في البداية
void insertAtBeginning(Node* &head, int value) {
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = head; // نربط الجديدة بالقديمة الأول
    head = newNode;       // ننقل الـ head
}

// 3. دالة الطباعة
void displayList(Node* head) {
    Node* current = head; // مؤشر مؤقت عشان الـ head ميتغيرش
    while (current != NULL) {
        cout << current->data << " -> ";
        current = current->next; // خطوة للمام
    }
    cout << "NULL" << endl;
}

}

ملخص الامتحان والمراجعة السريعة (Notebook & Exam Cheatsheet)

[المحاضرة الثانية: عمليات المرور والإضافة في البداية]
1. TRAVERSAL OPERATION (عملية المرور والطباعة على القائمة):
Definition:
Visiting every node in the linked list sequentially from head to end.
▪التوضيح بالعامية:
دي عملية بنلف بيها على كل عقدة في القايمة من أول الـ head لحد الآخر، عشان نطبع
القيم أو نعد عدد العقد أو ندور على رقم معين.
Loop Condition (شرط تكرار اللوب):
while (current != NULL)
▪التوضيح بالعامية:
معناه: "يا لوب، خليك شغال طول ما المؤشر current ماسك عقدة حقيقية في إيده،
وأول ما يلاقي قدامه فراغ (NULL) يقف فوراً لأن القايمة خلصت".
Step Forward (خطوة المشي للأمام):
current = current->next;
▪التوضيح بالعامية:
دي خطوة الساقية؛ بنقول للمؤشر current: "سيب العقدة الحالية اللي أنت واقف عندها
وانقل نفسك للعقدة اللي بعدها"، ولو نسينا السطر ده المؤشر هيفضل واقف مكانه
والبرنامج هيهنج ويدخل في Infinite Loop.
Golden Rule (القاعدة الذهبية):
Never move the original head pointer during traversal; always use a temporary pointer.
▪التوضيح بالعامية:
إياك تحرك الـ head الأصلي في اللوب أبداً! دايماً اعمل مؤشر مؤقت مساعد (زي current)
يلف هو، وسيب الـ head واقف حارس لأول القايمة عشان متضيعش منك في الذاكرة.
Time Complexity: O(n)
▪التوضيح بالعامية:
الوقت خطي، يعني لو عندك 10 عقد هتمشي 10 خطوات، ولو مليون عقدة هتمشي مليون خطوة.
2. INSERTION AT BEGINNING (عملية الإضافة في أول القائمة):
The 4 Golden Steps (الخطوات الأربعة بالترتيب الإلزامي):
1. Allocate new node:
Node* newNode = new Node();
▪بالعامية: بنطلب من الـ Heap يحجز لنا علبة جديدة في الميموري لم تكن موجودة.
2. Set data:
newNode->data = value;
▪بالعامية: بنفتح جيب الـ data في العلبة الجديدة ونحط فيه الرقم اللي عايزينه.
3. Link new node to the current head:
newNode->next = head;
▪بالعامية: بنشد حبل ونربط العقدة الجديدة بالقائمة القديمة الأول قبل أي حاجة.
4. Update head pointer:
head = newNode;
▪بالعامية: بعد ما اطمنا إن العقدة الجديدة مسكت في السلسلة، بننقل مؤشر الـ head
ونخليه يشاور عليها وتبقى هي رسمياً أول عقدة.
Pass by Reference (سر علامة &):
Must use (Node* &head) in the function parameter.
▪التوضيح بالعامية:
لازم نحط علامة & جنب المؤشر، لأننا بنغير مكان الـ head الأصلي نفسه، ومن غير &
لغة C++ هتعمل نسخة مؤقتة والتعديل مش هيسمع في الـ main وهتفضل القايمة زي ما هي.
Critical Exam Warning (تحذير امتحاني خطير):
Always link the new node to the list BEFORE updating the head pointer.
▪التوضيح بالعامية:
لو عكست السطرين وقلت head = newNode الأول، الـ head هيسيب القايمة القديمة
وهتضيع كل العقد القديمة في الذاكرة للأبد (Memory Leak)! اربط الأول وبعدين انقل الـ head.
Time Complexity: O(1)
▪التوضيح بالعامية:
الوقت لحظي وثابت ومش معتمد على عدد العناصر، لأننا مش بنلف في لوب ومش بنزق
عناصر زي المصفوفات؛ مجرد سطرين ربط أسهم فقط!

void insertAtEnd(Node* &head, int value) {
    // خطوة 1: حجز العقدة الجديدة وتجهيزها
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = NULL; // لأنها هتكون آخر عقدة في القائمة

    // خطوة 2: فحص الحالة الخاصة (لو القائمة كانت فاضية أصلاً)
    if (head == NULL) {
        head = newNode;
        return;
    }

    // خطوة 3: المشي بمؤشر مؤقت للوصول لآخر عقدة
    Node* temp = head;
    while (temp->next != NULL) {
        temp = temp->next;
    }

    // خطوة 4: ربط العقدة الأخيرة بالعقدة الجديدة
    temp->next = newNode;
}

C++ Code 
#include <iostream>
using namespace std;

// 1. تعريف قالب العقدة
struct Node {
    int data;
    Node* next;
};

// 2. دالة الإضافة في النهاية
void insertAtEnd(Node* &head, int value) {
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = NULL;

    // الحالة الخاصة: لو القائمة فارغة
    if (head == NULL) {
        head = newNode;
        return;
    }

    // المشي لآخر عقدة
    Node* temp = head;
    while (temp->next != NULL) {
        temp = temp->next;
    }

    // الربط في النهاية
    temp->next = newNode;
}

// 3. دالة الطباعة
void displayList(Node* head) {
    Node* current = head;
    while (current != NULL) {
        cout << current->data << " -> ";
        current = current->next;
    }
    cout << "NULL" << endl;
}

int main() {
    Node* head = NULL;

    // تجربة الإضافة في النهاية
    insertAtEnd(head, 100);
    insertAtEnd(head, 200);
    insertAtEnd(head, 300);

    // طباعة الناتج
    cout << "List after inserting at end: ";
    displayList(head);

    return 0;
}

ملخص الامتحان والمراجعة السريعة (Notebook & Exam Cheatsheet)

[المحاضرة الثانية: الإضافة في نهاية القائمة]
1. INSERTION AT END (عملية الإضافة في نهاية القائمة):
Definition:
Adding a new node after the current last node of the linked list.
▪التوضيح بالعامية:
إننا نضيف عقدة جديدة في ديل القايمة بعد آخر عقدة موجودة حالياً.
The Critical Loop Condition (شرط اللوب الجوهري للوصول للآخر):
while (temp->next != NULL)
▪التوضيح بالعامية:
الشرط ده بيخلي المؤشر temp يقف برجليه على العقدة الأخيرة نفسها ومينزلش في الفراغ،
عشان نقدر نفتح جيب الـ next بتاعها ونربطه بالعقدة الجديدة.
▪تحذير امتحاني:
لو كتبت while (temp != NULL)، المؤشر هيخرج برة القايمة ويقف عند NULL،
ولما تيجي تقول temp->next البرنامج هيعمل Crash فوري (Segmentation Fault)!
Edge Case: Empty List (الحالة الخاصة لما تكون القائمة فاضية):
if (head == NULL) { head = newNode; return; }
▪التوضيح بالعامية:
لو القايمة فاضية أصلاً، مفيش عقد نمشي عليها، فالعقدة الجديدة دي بتكون هي أول
عقدة وآخر عقدة في نفس الوقت، وبنخلي الـ head يشاور عليها مباشرة ونخرج.
Linking Step (خطوة الربط):
temp->next = newNode;
▪التوضيح بالعامية:
بنشيل الـ NULL اللي في آخر عقدة قديمة، ونحط مكانه عنوان العقدة الجديدة.
Time Complexity: O(n)
▪التوضيح بالعامية:
الوقت خطي O(n) لأننا معندناش إندكس يقفز للآخر مباشرة؛ مجبرين نبدأ من الـ head
ونلف على كل العقد لحد ما نوصل لآخر عقدة في القايمة.

Q2: To stop a temporary pointer `temp` exactly at the LAST node of a linked list, what should the loop condition be?
A) `while (temp != NULL)`
✅ B) `while (temp->next != NULL)`
C) `while (temp->data != NULL)`
D) `while (head != NULL)`
💡 Correct Answer: B
التفسير الأكاديمي والعامي: الشرط الصحيح هو `temp->next != NULL`؛ لأنه يتوقف عندما يصبح مؤشر العقدة التالية فارغاً، أي عندما يقف المؤشر على العقدة الأخيرة تماماً. أما الخيار A فيجعله يتجاوز العقدة الأخيرة ويقف في الفراغ NULL.
Q3: What will happen if we omit the check `if (head == NULL)` when inserting at the end of an initially empty linked list?
A) The node will be added normally.
✅ B) The program will crash with a Null Pointer Exception when accessing `temp->next`.
C) The compiler will produce a syntax error.
D) An infinite loop will occur.
💡 Correct Answer: B
التفسير الأكاديمي والعامي: لو كانت القائمة فارغة، فإن head يساوي NULL، وإذا حاولنا عمل temp = head ثم فحص `temp->next`، فنحن نحاول قراءة حقل من عنوان غير موجود (NULL)، مما يسبب انهيار البرنامج فوراً (Null Pointer Dereference / Crash).
Q4: In `insertAtEnd`, after finding the last node using `temp`, how is the new node attached?
A) `newNode->next = temp;`
B) `head = newNode;`
✅ C) `temp->next = newNode;`
D) `temp = newNode->next;`
💡 Correct Answer: C
التفسير الأكاديمي والعامي: لربط العقدة الجديدة في النهاية، نقوم بتعديل مؤشر next الخاص بالعقدة الأخيرة التي يقف عندها temp ليصبح حاملاً لعنوان العقدة الجديدة `newNode`.

void insertAfter(Node* prevNode, int value) {
    // 1. فحص الأمان: التأكد من أن العقدة السابقة موجودة فعلاً
    if (prevNode == NULL) {
        cout << "The given previous node cannot be NULL!" << endl;
        return;
    }

    // 2. حجز العقدة الجديدة وملء قيمتها
    Node* newNode = new Node();
    newNode->data = value;

    // 3. ربط العقدة الجديدة بالعقدة التي تلي prevNode (الحبل الأول)
    newNode->next = prevNode->next;

    // 4. ربط العقدة السابقة بالعقدة الجديدة (الحبل الثاني)
    prevNode->next = newNode;
}

إليك الكود المعتمد لهذه العملية:

void insertAtPosition(Node* &head, int value, int position) {
    // لو طلب الإضافة في الموقع 1 (أي في البداية)
    if (position == 1) {
        Node* newNode = new Node();
        newNode->data = value;
        newNode->next = head;
        head = newNode;
        return;
    }

    // المشي للوصول للعقدة التي تسبق الموضع المطلوب (position - 1)
    Node* temp = head;
    for (int i = 1; i < position - 1 && temp != NULL; i++) {
        temp = temp->next;
    }

    // فحص لو كان الموضع المطلوب خارج حدود القائمة
    if (temp == NULL) {
        cout << "Position out of bounds!" << endl;
        return;
    }

    // نفس خطوتي الربط السحريتين
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = temp->next; // 1. ربط الجديدة باللاحقة
    temp->next = newNode;       // 2. ربط السابقة بالجديدة
}

C++ Code 
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

// دالة الإضافة في النهاية (لتجهيز القائمة)
void insertAtEnd(Node* &head, int value) {
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = NULL;

    if (head == NULL) {
        head = newNode;
        return;
    }

    Node* temp = head;
    while (temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode;
}

// دالة الإضافة بعد عقدة محددة
void insertAfter(Node* prevNode, int value) {
    if (prevNode == NULL) {
        cout << "Previous node cannot be NULL!" << endl;
        return;
    }

    Node* newNode = new Node();
    newNode->data = value;

    // خطوتا التوصيل
    newNode->next = prevNode->next; // 1. الجديدة تمسك اللاحقة
    prevNode->next = newNode;       // 2. السابقة تمسك الجديدة
}

// دالة الطباعة
void displayList(Node* head) {
    Node* current = head;
    while (current != NULL) {
        cout << current->data << " -> ";
        current = current->next;
    }
    cout << "NULL" << endl;
}

int main() {
    Node* head = NULL;

    // بناء: 10 -> 20 -> 40
    insertAtEnd(head, 10);
    insertAtEnd(head, 20);
    insertAtEnd(head, 40);

    cout << "Before insert: ";
    displayList(head);

    // العقدة 20 هي العقدة الثانية (head->next)
    Node* node20 = head->next;

    // إضافة 30 بعد العقدة 20
    insertAfter(node20, 30);

    cout << "After inserting 30: ";
    displayList(head);

    return 0;
}

[المحاضرة الثانية: الإضافة في موضع محدد]
1. INSERTION AFTER A GIVEN NODE (الإضافة بعد عقدة محددة):
Definition:
Inserting a new node into the list immediately following a specified existing node.
▪التوضيح بالعامية:
إننا نزرع عقدة جديدة في وسط القائمة بعد عقدة معينة إحنا عارفين مكانها.
The 2 Golden Linking Steps (خطوتا الربط بالترتيب الإلزامي):
1. newNode->next = prevNode->next;
▪بالعامية: العقدة الجديدة تشد حبل وتمسك العقدة اللي بعدنا الأول عشان متهربش من الميموري.
2. prevNode->next = newNode;
▪بالعامية: العقدة السابقة تسيب اللي وراها وتمسك في العقدة الجديدة، وبكده السلسلة اكتملت.
Safety Check (فحص الأمان لمنع الـ Crash):
if (prevNode == NULL) return;
▪التوضيح بالعامية:
لازم نتأكد إن العقدة السابقة موجودة فعلاً ومش بتشاور على فراغ، عشان البرنامج ميعملش Crash.
Time Complexity:
▪If prevNode pointer is already given: O(1)
(لو المؤشر في إيدنا مباشرة بتاخد خطوة واحدة ثابتة).
▪If we must search / traverse to find position k: O(n)
(لو لازم نلف بلوب من الأول عشان نوصل للمكان المطلوب بتاخد وقت خطي).
2. SUMMARY OF ALL 3 INSERTION OPERATIONS (ملخص عمليات الإضافة الثلاث للامتحان):
OperationTime ComplexityKey Pointer Manipulation
Insert at Beginning (Head)O(1)newNode->next = head; head = newNode;
Insert at End (Tail)O(n)while(temp->next != NULL); temp->next = newNode;
Insert After (Given Node)O(1)newNode->next = prev->next; prev->next = newNode;

أسئلة الامتحانات بالحل والتفسير الأكاديمي والعامي (Exam MCQs)

Q1: To insert a new node `newNode` after an existing node `prevNode`, what is the correct sequence of pointer assignments?
A) `prevNode->next = newNode;` followed by `newNode->next = prevNode->next;`
✅ B) `newNode->next = prevNode->next;` followed by `prevNode->next = newNode;`
C) `newNode->next = head;` followed by `head = newNode;`
D) `prevNode->next = NULL;` followed by `newNode->next = prevNode;`
💡 Correct Answer: B
التفسير الأكاديمي والعامي: يجب أولاً ربط العقدة الجديدة بالعقدة التالية (`newNode->next = prevNode->next`) لضمان عدم ضياع بقية القائمة في الذاكرة، ثم بعد ذلك توجيه مؤشر العقدة السابقة إليها.
Q2: What will happen if you execute `prevNode->next = newNode;` FIRST when inserting a node in the middle of a linked list?
A) The new node is inserted at the head of the list.
✅ B) The remaining sublist following `prevNode` is lost from memory.
C) The code compiles and works without any flaws.
D) Memory is automatically deallocated by the compiler.
💡 Correct Answer: B
التفسير الأكاديمي والعامي: تقديم هذا السطر يجعل العقدة السابقة تفقد عنوان العقد التي تليها قبل أن تمسك بها العقدة الجديدة، مما يسبب ضياع بقية القائمة في الذاكرة (Memory Leak).
Q3: Given a pointer to a specific node `p` in a singly linked list, what is the time complexity to insert a new node immediately after `p`?
A) O(n)
B) O(n log n)
✅ C) O(1)
D) O(n^2)
💡 Correct Answer: C
التفسير الأكاديمي والعامي: طالما أن مؤشر العقدة `p` موجود ومعلوم لدينا بالفعل، فإن الإضافة بعدها لا تتطلب أي حلقات تكرار أو بحث، وتتم في خطوتين ثابتتين للربط، فتستغرق وقتاً ثابتاً O(1).
Q4: What condition indicates that `insertAfter(prevNode, val)` was called with an invalid node?
A) `prevNode->next == NULL`
✅ B) `prevNode == NULL`
C) `prevNode->data == 0`
D) `head == NULL`
💡 Correct Answer: B
التفسير الأكاديمي والعامي: إذا كان `prevNode == NULL` فهذا يعني أن المؤشر لا يشير لأي عقدة حقيقية، ومحاولة الوصول لحقوله ستؤدي لانهيار البرنامج فوراً.

void deleteNode(Node* &head, int key) {
    // خطوة 1: فحص القائمة الفارغة
    if (head == NULL) {
        cout << "List is empty!" << endl;
        return;
    }

    // خطوة 2: حالة خاصة: لو كانت العقدة المراد مسحها هي أول عقدة نفسها
    if (head->data == key) {
        Node* temp = head;
        head = head->next;
        delete temp;
        return;
    }

    // خطوة 3: البحث عن العقدة ومسك العقدة السابقة لها
    Node* current = head;
    Node* prev = NULL;

    while (current != NULL && current->data != key) {
        prev = current;           // prev يأخذ مكان current الحالي
        current = current->next;  // current يتقدم خطوة للأمام
    }

    // خطوة 4: فحص لو الرقم غير موجود أصلاً في القائمة
    if (current == NULL) {
        cout << "Value " << key << " not found in the list!" << endl;
        return;
    }

    // خطوة 5: القفز وتخطي العقدة ثم حذفها
    prev->next = current->next;
    delete current;
}

#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

// إضافة في النهاية
void insertAtEnd(Node* &head, int value) {
    Node* newNode = new Node();
    newNode->data = value;
    newNode->next = NULL;

    if (head == NULL) {
        head = newNode;
        return;
    }

    Node* temp = head;
    while (temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode;
}

// 1. حذف من البداية
void deleteFromBeginning(Node* &head) {
    if (head == NULL) return;

    Node* temp = head;
    head = head->next;
    delete temp;
}

// 2. حذف عقدة بقيمة محددة
void deleteNode(Node* &head, int key) {
    if (head == NULL) return;

    if (head->data == key) {
        Node* temp = head;
        head = head->next;
        delete temp;
        return;
    }

    Node* current = head;
    Node* prev = NULL;

    while (current != NULL && current->data != key) {
        prev = current;
        current = current->next;
    }

    if (current == NULL) return;

    prev->next = current->next;
    delete current;
}

// طباعة
void displayList(Node* head) {
    Node* current = head;
    while (current != NULL) {
        cout << current->data << " -> ";
        current = current->next;
    }
    cout << "NULL" << endl;
}

int main() {
    Node* head = NULL;

    // بناء: 10 -> 20 -> 30 -> 40 -> 50
    insertAtEnd(head, 10);
    insertAtEnd(head, 20);
    insertAtEnd(head, 30);
    insertAtEnd(head, 40);
    insertAtEnd(head, 50);

    cout << "Original List: ";
    displayList(head);

    // حذف 10 من البداية
    deleteFromBeginning(head);
    cout << "After deleting head (10): ";
    displayList(head);

    // حذف 30 من المنتصف
    deleteNode(head, 30);
    cout << "After deleting 30: ";
    displayList(head);

    return 0;
}

[المحاضرة الثانية: عمليات الحذف]
1. DELETION FROM BEGINNING (الحذف من بداية القائمة):
Definition:
Removing the first node (head node) and advancing head to the next node.
▪التوضيح بالعامية:
مسح أول عقدة وتوجيه مؤشر head للعقدة الثانية اللي وراها على طول.
Steps:
1. Node* temp = head; // مسك أول عقدة بمؤشر مؤقت
2. head = head->next; // تقديم head للعقدة الثانية
3. delete temp; // تحرير مساحة الأولى من الـ RAM
▪تحذير امتحاني من تسريب الذاكرة (Memory Leak):
لو كتبت head = head->next بدون استخدام delete temp، العقدة الأولى تفضل محجوزة
في الـ RAM ومش هتعرف توصلها أبداً، وده خطأ هندسي فادح اسمه Memory Leak!
Time Complexity: O(1)
▪التوضيح بالعامية:
وقت لحظي ثابت لأننا بنعدل المؤشرات مباشرة بدون أي لوب.
2. DELETION BY VALUE (حذف عقدة بقيمة معينة في المنتصف أو النهاية):
Definition:
Searching for a target node, unlinking it by connecting its previous node
to its next node, and freeing its allocated memory.
▪التوضيح بالعامية:
إننا ندور على عقدة معينة، ونخلي العقدة اللي قبلها تنط فوقها وتمسك في اللي بعدها،
وبعدين نعدم العقدة المطلوبة بـ delete.
Two-Pointer Technique (تكنيك المؤشرين):
▪current: يفتش عن العقدة المطلوب مسحها.
▪prev: يمشي خلف current دائماً ليمسك العقدة السابقة لتغيير مؤشرها.
Linking & Deletion Steps:
1. prev->next = current->next; // السابقة تمسك اللاحقة
2. delete current; // إعدام العقدة وتحرير مساحتها
Time Complexity: O(n)
▪التوضيح بالعامية:
الوقت خطي لأننا في أسوأ حالة ممكن نلف على القايمة كلها عشان نلاقي الرقم المطلوب.

ملخص الامتحان والمراجعة السريعة (Notebook & Exam Cheatsheet)

[المحاضرة الثانية: أنواع القوائم المتصلة والمصطلحات]
1. TYPES OF LINKED LISTS (أنواع القوائم المتصلة للامتحان):
Singly Linked List (SLL):
▪Traversal: Forward only (Unidirectional).
▪Pointers per node: 1 pointer (next).
▪Last node points to: NULL.
▪بالعامية: شارع اتجاه واحد، كل عقدة ماسكة اللي بعدها بس، والأخيرة بتبص على NULL.
Doubly Linked List (DLL):
▪Traversal: Both Forward and Backward (Bidirectional).
▪Pointers per node: 2 pointers (next and prev).
▪First node prev points to: NULL.
▪Last node next points to: NULL.
▪بالعامية: شارع اتجاهين، كل عقدة ماسكة اللي بعدها واللي قبلها، فتقدر ترجع لورا براحتك.
Circular Linked List (CLL):
▪Traversal: Circular loop (No end).
▪Last node next points to: Head node (First node).
▪No node points to: NULL (مفيش فيها NULL نهائياً).
▪Loop stop condition: while (temp != head).
▪بالعامية: دائرة مقفولة، العقدة الأخيرة لافة وماسكة في أول عقدة، ومفيهاش أي NULL.
2. COMPREHENSIVE GLOSSARY (قاموس مصطلحات المحاضرة الثانية بالكامل):
Linked List : A dynamic linear data structure of nodes connected via pointers.
(هيكل بيانات خطي ديناميكي مكون من عقد متصلة بمؤشرات).
Node : An individual element storing a data value and pointer(s).
(اللبنة الأساسية المكونة من حقل بيانات وحقل مؤشر).
Head Pointer : The anchor pointer referencing the first node in the list.
(المؤشر الرئيسي الذي يحفظ عنوان أول عقدة).
Tail / Last Node : The final node in the list, whose next pointer is NULL.
(العقدة الأخيرة في القائمة ومؤشرها يشير إلى NULL).
Self-Referential Type : A structure containing a pointer to its own type.
(هيكل يحتوي على مؤشر يشير لنفس نوع الهيكل).
Memory Leak : Allocated memory that is unlinked without being deleted.
(تسريب الذاكرة: حجز مساحة دون تحريرها بالأمر delete بعد الاستغناء عنها).
Traversal : Iterating through each node sequentially from head to end.
(عملية المرور التسلسلي على العقد واحدة تلو الأخرى).
Arrow Operator (->) : Shorthand syntax combining pointer dereference and field access (*p).f.
(معامل السهم للانتقال لموقع المؤشر وفتح الحقل المطلوب بداخله).
