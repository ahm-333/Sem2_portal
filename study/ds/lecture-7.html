01

المقارنة: الهياكل الخطية vs غير الخطية (Linear vs Non-linear)

Slides 3–13
Linear Data Structures: Elements form a sequence. Relationship is represented by sequential memory locations (Arrays) or pointers (Linked Lists).
Non-linear Data Structures: Elements are not organized in a sequential fashion; an item can be attached to several other elements to reflect a hierarchical or network relationship (Trees, Graphs).

💡 بالبلدي كده: ليه محتاجين شجرة ومش كفاية المصفوفة والقائمة؟

في الفصول اللي فاتت درسنا الـ Array والـ Linked List والـ Stack والـ Queue. كل دي اسمها Linear Data Structures (هياكل خطية). يعني إيه خطية؟ يعني العناصر مرصوصة ورا بعض زي الطابور، كل عنصر ليه واحد قبله وواحد بعده بس!

طب تخيل طلبوا منك تعمل سيستم لشركة فيها: رئيس مجلس إدارة، تحته 3 مدراء قطاعات، وكل مدير تحته 5 رؤساء أقسام، وكل رئيس قسم تحته 10 مهندسين! لو حطيتهم في جدول أو مصفوفة، هتعرف أسماءهم، بس مش هتعرف مين رئيس مين ولا التدرج الوظيفي (Hierarchy) ماشي إزاي! هنا ظهرت الـ Non-linear Data Structures وأشهرها الـ Tree، لأنها معمولة مخصوص عشان تمثل العلاقات الهرمية والتفرعات المتعددة!

02

قاموس ومصطلحات الأشجار الأكاديمية (Tree Terminology)

Slides 14–31

علماء الحاسب لما جم يصمموا الـ Tree، اتخيلوا شجرة طبيعية مقلوبة: الجذر (Root) فوق في قمة الشجرة، والفروع والأوراق بتنزل لتحت! وفي مصطلحات محددة بتيجي دايماً في أسئلة الامتحان والـ MCQs لازم تكون حافظ معناها وفاهم حساباتها بالملي:

🌲 الخريطة البصرية الشاملة لمصطلحات الشجرة (Root, Leaves, Height, Depth, Siblings)

الأوراق E, F, G, H, I. ارتفاع الشجرة 3 (أطول مسار A → B → D → H طوله 3 حواف) وعدد العقد Size = 9

1. الجذر (Root):

العقدة الأولى والوحيدة في قمة الشجرة التي ليس لها أي أب (Parent = NULL). كل شجرة لها جذر واحد فقط (في الرسمة العقدة A).

2. الأب والابن (Parent and Child):

إذا كانت العقدة متصلة بعقدة تالية أسفلها بحافة، تكون العقدة العليا هي الـ Parent والسفلى هي الـ Child. العقدة B هي أب لكل من D و E.

3. الإخوة (Siblings / Brothers):

العقد التي تشترك في نفس الأب بالضبط! العقدتان B و C إخوة لأن والدهما هو A، بينما D و F ليسا إخوة لأن لكل منهما أب مختلف.

4. الأوراق والعقد الداخلية (Leaf vs Internal Node):

الورقة (Leaf / External Node): عقدة لا تملك أي أبناء على الإطلاق (Degree = 0) مثل H, I, E, F, G.
العقدة الداخلية (Internal Node): أي عقدة تملك ابناً واحداً على الأقل (مثل A, B, C, D).

5. الحسابات الذهبية: العمق والارتفاع (Depth vs Height):

  • العمق أو المستوى (Depth / Level of Node): طول المسار من الجذر وصولاً لتلك العقدة (كم حافة تنزلها من فوق؟). عمق الجذر دائماً 0، وعمق B هو 1، وعمق H هو 3.
  • الارتفاع (Height of Node): أطول مسار من تلك العقدة نزولاً لأسفل إلى أبعد ورقة. ارتفاع أي ورقة (Leaf) يساوي دائماً 0!
  • ارتفاع الشجرة كاملة (Height of Tree): هو نفسه ارتفاع الجذر (Height of Root) وهو هنا 3.

6. درجة العقدة ودرجة الشجرة (Degree):

Degree of a Node: عدد الأبناء المتصلين بتلك العقدة مباشرة.
Degree of the Tree: أقصى درجة عقدة موجودة في الشجرة كاملة (Max Degree).

03

الشجرة الثنائية وتشريح الذاكرة (Binary Tree Representation)

Slides 32–36
Binary Tree Definition: A binary tree is a hierarchical data structure where every node has at most two children, referred to as the left child and the right child.

💡 الشجرة الثنائية في الـ C++: علبة بثلاث خانات!

فاكر لما قلنا في القوائم المتصلة (Linked List) إن العقدة فيها حتتين: data و next؟ في الشجرة الثنائية، العقدة بتكبر سنة وتبقى ثلاث خانات: 1. خانة تشيل القيمة (data). 2. مؤشر يشاور على الابن الشمال (left pointer). 3. مؤشر يشاور على الابن اليمين (right pointer). ولو العقدة معندهاش ابن شمال أو يمين، المؤشر ده بيبقى nullptr! 

// تعريف عقدة الشجرة الثنائية بلغة C++
struct Node {
    int data;           // القيمة المخزنة
    Node* left;         // مؤشر للابن الأيسر
    Node* right;        // مؤشر للابن الأيمن

    // باني العقدة Constructor
    Node(int val) : data(val), left(nullptr), right(nullptr) {}
};

مصطلحان هامان في سلايدات الدفعة (Slide 35):

1. الأشجار المتشابهة (Similar Trees):

شجرتان لهما نفس الهيكل والشكل الهندسي بالضبط ولكن القيم المخزنة داخل العقد قد تكون مختلفة تماماً!

2. الأشجار المتطابقة (Copies of Trees):

شجرتان لهما نفس الهيكل ونفس القيم المخزنة في كل عقدة بالملي (نسخة طبق الأصل).

04

خوارزميات المرور والتنقل (Tree Traversals)

Slides 37–46
Tree Traversal: The process of visiting each node in the tree exactly once in a systematic way. There are four primary algorithms: Pre-order, In-order, Post-order (Depth-First Search using Recursion), and Breadth-First Order (using Queue).

💡 سر حفظ الخوارزميات الثلاث: مكان كلمة الجذر (Root)!

عشان متتلخبطش نهائي في الامتحان، اسم الخوارزمية بيحدد إنت بتزور الجذر (Root / Data) إمتى بالنسبة لأولاده (Left و Right): دائماً وأبداً: الشمال بيجي قبل اليمين (Left always before Right)! التغيير الوحيد هو مكان الـ Root:

  • • Pre-order (من البداية): Root → Left → Right (الجذر في الأول).
  • • In-order (في الوسط): Left → Root → Right (الجذر في النص).
  • • Post-order (في النهاية): Left → Right → Root (الجذر في الآخر).
🌳 شجرة المثال المعتمدة في السلايدات للتتبع (Slide 39, 42, 45)

شجرة مكونة من 7 عقد: الجذر A، فرعه الأيسر B (وتحته D, E)، وفرعه الأيمن C (وتحته G, F)

1

Pre-order Traversal (المرور القبلي: Root ➔ Left ➔ Right)

نطبع قيمة العقدة الحالية أولاً، ثم نستدعي الدالة ذاتياً للفرع الأيسر كاملاً، ثم نستدعيها للفرع الأيمن.

Pre-order Output: A, B, D, E, C, G, F 
void print_preorder(Node* root) {
    if (root != nullptr) {
        cout << root->data << " ";      // 1. Visit Root
        print_preorder(root->left);     // 2. Traverse Left Subtree
        print_preorder(root->right);    // 3. Traverse Right Subtree
    }
}
2

In-order Traversal (المرور البيني: Left ➔ Root ➔ Right)

عند كل عقدة، نزور كل عقد الفرع الشمال الأول بنفس القاعدة، بعدين نطبع قيمة العقدة الحالية، وبعدها نزور كل عقد الفرع اليمين. لو فرع فاضي، بنتخطّاه. في شجرة البحث الثنائية (BST)، المرور البيني بيطبع القيم بالترتيب التصاعدي (Sorted Order).

In-order Output: D, B, E, A, G, C, F 
void print_inorder(Node* root) {
    if (root != nullptr) {
        print_inorder(root->left);      // 1. Traverse Left Subtree
        cout << root->data << " ";      // 2. Visit Root
        print_inorder(root->right);     // 3. Traverse Right Subtree
    }
}
3

Post-order Traversal (المرور البعدي: Left ➔ Right ➔ Root)

نزور الأبناء أولاً (اليسار ثم اليمين)، ولا نزور العقدة الجذرية إلا بعد الانتهاء التام من جميع فروعها! وتستخدم هذه الخوارزمية في حذف الشجرة وتفريغ الذاكرة (Delete Tree) وحساب مساحات المجلدات في أنظمة الملفات.

Post-order Output: D, E, B, G, F, C, A 
void print_postorder(Node* root) {
    if (root != nullptr) {
        print_postorder(root->left);     // 1. Traverse Left Subtree
        print_postorder(root->right);    // 2. Traverse Right Subtree
        cout << root->data << " ";       // 3. Visit Root
    }
}
4

Breadth-First / Level-Order (المرور بالمستويات باستخدام الطابور Queue)

نزور الشجرة مستوى بمستوى من فوق لتحت ومن الشمال لليمين. عشان نحافظ على ترتيب المستويات بنستخدم طابور (Queue): نطرد العقدة من الطابور ونطبعها، ونضيف أولادها في آخر الطابور!

Level-Order Output: A, B, C, D, E, G, F 
#include <queue>
void print_level_order(Node* root) {
    if (root == nullptr) return;
    queue<Node*> q;
    q.push(root);

    while (!q.empty()) {
        Node* current = q.front();
        q.pop();
        cout << current->data << " ";

        if (current->left != nullptr) q.push(current->left);
        if (current->right != nullptr) q.push(current->right);
    }
}

خوارزميات وعمليات الأشجار الشائعة (Tree Operations)

Slides 47–51

1. حساب إجمالي عدد العقد (Node Count):

باستخدام مبدأ فرق تسد (Divide and Conquer): عدد عقد الشجرة = 1 (الجذر) + عدد عقد الفرع الأيسر + عدد عقد الفرع الأيمن!

int node_count(Node* root) {
    if (root == nullptr) return 0;
    return 1 + node_count(root->left) + node_count(root->right);
}

2. حساب أقصى ارتفاع للشجرة (Tree Height):

ارتفاع الشجرة هو أقصى ارتفاع بين الفرع الأيسر والأيمن + 1.

int tree_height(Node* root) {
    if (root == nullptr) return -1; // لو بنحسب بعدد الحواف (Edges)
    return 1 + max(tree_height(root->left), tree_height(root->right));
}

3. حساب عدد الأوراق فقط (Leaf Count):

العقدة تعتبر ورقة إذا كان left == nullptr && right == nullptr.

int leaf_count(Node* root) {
    if (root == nullptr) return 0;
    if (root->left == nullptr && root->right == nullptr) return 1;
    return leaf_count(root->left) + leaf_count(root->right);
}

معمل التطبيق العملي: كود C++ متكامل وجاهز للتشغيل

Lab & Practice

برنامج متكامل يجمع إنشاء العقد يدوياً، التوصيل، وحساب العمليات، وطباعة نواتج المرور الأربعة لاختبار فهمك على بيئة Code::Blocks أو VS Code: 

#include <iostream>
#include <queue>
#include <algorithm>
using namespace std;

// 1. تعريف عقدة الشجرة الثنائية
struct Node {
    int data;
    Node* left;
    Node* right;

    Node(int val) : data(val), left(nullptr), right(nullptr) {}
};

// 2. خوارزميات المرور الثلاثة بالـ Recursion
void printPreorder(Node* root) {
    if (!root) return;
    cout << root->data << " ";
    printPreorder(root->left);
    printPreorder(root->right);
}

void printInorder(Node* root) {
    if (!root) return;
    printInorder(root->left);
    cout << root->data << " ";
    printInorder(root->right);
}

void printPostorder(Node* root) {
    if (!root) return;
    printPostorder(root->left);
    printPostorder(root->right);
    cout << root->data << " ";
}

// 3. المرور بالمستويات باستخدام الطابور BFS
void printLevelOrder(Node* root) {
    if (!root) return;
    queue<Node*> q;
    q.push(root);
    while (!q.empty()) {
        Node* curr = q.front();
        q.pop();
        cout << curr->data << " ";
        if (curr->left) q.push(curr->left);
        if (curr->right) q.push(curr->right);
    }
}

// 4. العمليات الإحصائية
int countNodes(Node* root) {
    if (!root) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}

void deleteTree(Node* root) {
    if (!root) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    /* بناء الشجرة المعمارية:
             1
           /   \
          2     3
         / \   / \
        4   5 6   7
    */
    Node* root = new Node(1);
    root->left = new Node(2);
    root->right = new Node(3);
    root->left->left = new Node(4);
    root->left->right = new Node(5);
    root->right->left = new Node(6);
    root->right->right = new Node(7);

    cout << "Preorder:   "; printPreorder(root);   cout << "\n";
    cout << "Inorder:    "; printInorder(root);    cout << "\n";
    cout << "Postorder:  "; printPostorder(root);  cout << "\n";
    cout << "Level-Order: "; printLevelOrder(root); cout << "\n";
    cout << "Total Nodes: " << countNodes(root) << "\n";

    deleteTree(root);
    return 0;
}
