1. ما هو الـ Recursion؟ (المنطق من الصفر)

التعريف الأكاديمي المكتوب نصاً في سلايد 4:

Recursion Definition: Process of solving a problem by reducing it to smaller versions of itself.

💡 الشرح بالعامية البسيطة:

في البرمجة العادية، إحنا متعودين إن الدالة لما تخلص شغلها بتسلم الناتج للـ main.

أما الـ Recursion (الاستدعاء الذاتي) فبيقولك:

  • لو عندك مشكلة حسابية كبيرة ومعقدة، متحلهاش كلها في خطوة واحدة!
  • حل جزء صغير منها، وباقي المشكلة هتلاقيه نفس المشكلة الأصلية بالظبط بس بأرقام أصغر.
  • فالدالة تقوم منادية "نسخة من نفسها" تديلها الأرقام الأصغر دي، وتفضل الدالة تصغر المشكلة وتستدعي نفسها، لحد ما نوصل لأبسط رقم نعرف إجابته فوراً بدون أي حسابات!

2. مثال السلايد التأسيسي: مسألة المضروب (The Factorial Problem)

السلايد بدأت بمضروب الرقم 5 (5!):

5! = 5 × 4 × 3 × 2 × 1 = 120
5! = 5 × (4 × 3 × 2 × 1) = 5 × 4!

الجزء اللي بين القوسين هو مضروب الـ 4 (4!)، وبنفس المنطق تتفكك السلسلة تدريجياً حتى نصل إلى الحقيقة الرياضية الثابتة (0! = 1):

4! = 4 × 3!
3! = 3 × 2!
2! = 2 × 1!
1! = 1 × 0!
0! = 1 (Base Case)

3. الركيزتان الإلزاميتان لأي دالة Recursion

أي دالة Recursion في العالم عشان تشتغل صح ومتهنجش، لازم المبرمج يقسمها لشقين إجباريين:

🎨 رسم توضيحي: المكونان الإجباريان لأي دالة استدعاء ذاتي (Recursion)

أ) حالة الأساس (Base Case):

Slide Definition: The case for which the solution is obtained directly; it stops the recursion.
  • دي الحالة البسيطة جداً اللي إحنا عارفين إجابتها بديهياً وبشكل مباشر من غير ما نحسب حاجة.
  • في المضروب: لما num == 0، الإجابة المباشرة هي 1.
  • وظيفتها: هي الفرامل التي توقف الاستدعاء؛ بدونها الدالة هتفضل تستدعي نفسها ومتقفش أبداً!

ب) الحالة العامة (General Case / Recursive Case):

Slide Definition: The case for which the solution is obtained indirectly using recursion.
Golden Rule: "General case must eventually reduce to a base case."
  • دي الحالة اللي بنحلها بطريقة غير مباشرة عن طريق إن الدالة تنادي نفسها بقيمة أصغر: fact(num) = num * fact(num - 1).
  • القاعدة الذهبية من السلايد: لازم في كل استدعاء نطرح أو نصغر الرقم عشان يقرب من الـ Base Case، مينفعش نكبره!

4. كود C++ الرسمي لدالة المضروب fact(num)

int fact(int num) {
    if (num == 0)
        return 1;                   // Base Case
    else
        return num * fact(num - 1); // General Case
}

5. التشريح الكامل للذاكرة: ماذا يحدث بالرسم عند تنفيذ fact(4)؟

في الـ RAM، يوجد جزء مخصص لإدارة الدوال اسمه مكدس الاستدعاءات (Call Stack). الدالة التي في الأسفل لا تستطيع إكمال عملية الضرب إلا عندما تنتهي الدالة التي فوقها وترجع بالناتج. التنفيذ يمر بمرحلتين:

المرحلة الأولى: مرحلة الصعود والتراكم (Winding / Calling Phase)

  1. استدعاء fact(4): يتجمد في الـ Stack منتظراً ناتج 4 * fact(3).
  2. استدعاء fact(3): يتجمد فوقه منتظراً ناتج 3 * fact(2).
  3. استدعاء fact(2): يتجمد فوقه منتظراً ناتج 2 * fact(1).
  4. استدعاء fact(1): يتجمد فوقه منتظراً ناتج 1 * fact(0).
  5. استدعاء fact(0): يصل إلى الـ Base Case (num == 0) فيرجع 1 فوراً بدون تجميد!

المرحلة الثانية: مرحلة الهبوط وحساب النواتج (Unwinding / Returning Phase)

  1. الدالة fact(0) ترجع بالرقم 1 وتُحذف من الـ Stack.
  2. الدالة fact(1) تستلم 1 وتحسب 1 * 1 = 1 وترجع 1.
  3. الدالة fact(2) تستلم 1 وتحسب 2 * 1 = 2 وترجع 2.
  4. الدالة fact(3) تستلم 2 وتحسب 3 * 2 = 6 وترجع 6.
  5. الدالة fact(4) تستلم 6 وتحسب 4 * 6 = 24 وترجع الناتج النهائي 24 للـ main!

🎨 رسم توضيحي (1): شكل مكدس الاستدعاءات (Call Stack) في قمة مرحلة الصعود

🎨 رسم توضيحي (2): مسار الاستدعاء (Winding) وإرجاع النواتج (Unwinding) في fact(4)

6. أنواع الـ Recursion الثلاثة وكارثة الاستدعاء اللانهائي

1. الاستدعاء المباشر (Directly Recursive Function) — سلايد 9:

Definition: A function that calls itself directly.

دالة fact تنادي دالة fact صراحة وبنفس الاسم داخل جسمها.

2. الاستدعاء غير المباشر (Indirectly Recursive Function) — سلايد 9:

Definition: A function calls another function, which eventually results in the original function call.

الدالة A تنادي الدالة B، وداخل الدالة B سطر ينادي الدالة A من جديد!

3. الاستدعاء ذو الذيل (Tail Recursive Function) — سلايد 9:

Definition: A recursive function where the LAST statement executed is the recursive call.

يكون استدعاء الدالة لنفسها هو آخر أمر تنفيذي في الدالة تماماً، ولا توجد بعده أي عملية ضرب أو جمع أو طباعة مؤجلة.

⚠️ كارثة الاستدعاء اللانهائي (Infinite Recursion) — سلايد 10:

  • السبب: يحدث عندما تستمر الدالة في استدعاء ن��سها للأبد دون أن تصل إلى الـ Base Case إطلاقاً (مثلاً لو نسينا كتابة شرط التوقف أو كبرنا الرقم بدلاً من تصغيره).
  • ماذا يحدث في عتاد الحاسوب والـ RAM؟ كل استدعاء يحجز صندوقاً (Stack Frame) في الذاكرة لتخزين المتغيرات والبارامترات. وبما أن ذاكرة الحاسوب محدودة (Finite system memory)، تمتلئ مساحة الـ Stack تماماً وينهار البرنامج فوراً بخطأ يسمى: Stack Overflow / Abnormal Termination.
💻 كود رقم (2) • تطبيق عملي متكامل للجزء الأول

تطبيق عملي: برنامج اختبار دالة المضروب fact

#include <iostream>
using namespace std;

int fact(int num) {
    if (num == 0)
        return 1;                   // Base Case
    else
        return num * fact(num - 1); // General Case
}

int main() {
    cout << "Testing fact(0) = " << fact(0) << endl; // 1
    cout << "Testing fact(3) = " << fact(3) << endl; // 6
    cout << "Testing fact(4) = " << fact(4) << endl; // 24

    return 0;
}

1. ما هي متتالية فيبوناتشي؟ (Fibonacci Sequence)

في سلايد 13، تبدأ متتالية فيبوناتشي القياسية بالأرقام التالية:

1, 1, 2, 3, 5, 8, 13, 21, 34, ...

💡 القاعدة الرياضية ببساطة:

إذا أعطينا أول رقمين في المتتالية (a1 و a2)، فإن أي رقم لاحق بدءاً من الرقم الثالث فصاعداً (n >= 3) يساوي حاصل جمع الرقمين السابقين له مباشرة!

an = a(n-1) + a(n-2)
  • الرقم الثالث: جمع الأول + الثاني = 1 + 1 = 2.
  • الرقم الرابع: جمع الثاني + الثالث = 1 + 2 = 3.
  • الرقم الخامس: جمع الثالث + الرابع = 2 + 3 = 5.
  • الرقم السادس: جمع الرابع + الخامس = 3 + 5 = 8.

2. دالة السلايد الرسمية: rFibNum(a, b, n) — سلايد 13 و 15:

صُممت دالة rFibNum (اختصار Recursive Fibonacci Number) لتعمل مع أي متتالية فيبوناتشي حتى لو لم تبدأ بـ (1, 1)، وتستقبل 3 معاملات:

int a

يمثل الرقم الأول في المتتالية (First Number).

int b

يمثل الرقم الثاني في المتتالية (Second Number).

int n

ترتيب الرقم المطلوب حسابه (n-th Fibonacci number).

3. كود C++ الرسمي لدالة rFibNum (سلايد 16)

int rFibNum(int a, int b, int n) {
    if (n == 1)
        return a;                                       // Base Case 1
    else if (n == 2)
        return b;                                       // Base Case 2
    else
        return rFibNum(a, b, n - 1) + rFibNum(a, b, n - 2); // General Case
}
🔍 تفكيك الكود سطر بسطر وكلمة بكلمة:

الوظيفة: ترويسة الدالة؛ تستقبل الحد الأول a والحد الثاني b وترتيب الحد المطلوب n، وترجع قيمته كعدد صحيح int.

if (n == 1) return a;

الوظيفة: حالة التوقف الأولى (Base Case 1)؛ إذا طلب المستخدم الرقم الأول في السلسلة (n == 1) نرجع القيمة a فوراً.

else if (n == 2) return b;

الوظيفة: حالة التوقف الثانية (Base Case 2)؛ إذا طلب المستخدم الرقم الثاني في السلسلة (n == 2) نرجع القيمة b فوراً.

ملاحظة امتحانية: دالة فيبوناتشي تحتاج حالتي توقف (Two Base Cases) إجبارياً لأن كل خطوة تعتمد على رقمين سابقين.
else return rFibNum(a, b, n - 1) + rFibNum(a, b, n - 2);

الوظيفة: الحالة العامة (General Case)؛ عندما يكون n >= 3 تنادي الدالة نفسها مرتين (شجرة ثنائية) لجمع الحد السابق n - 1 والحد الذي قبله n - 2.

+ عملية الجمع بين ناتجي الفرعين الأيسر والأيمن.
rFibNum(a, b, n - 2) الاستدعاء الذاتي الثاني لحساب قيمة العنصر الذي يسبق السابق.

أولاً: إيجاد أكبر عنصر في مصفوفة (Largest Element in an Array)

💡 الفكرة والمنطق الرياضي من السلايد (سلايد 19 و 20):

لدينا مصفوفة اسمها list تمتد من الفهرس lowerIndex (البداية) إلى الفهرس upperIndex (النهاية):

  • حالة التوقف (Base Case): إذا كان lowerIndex == upperIndex، فهذا يعني أن النطاق يحتوي على عنصر واحد فقط، فيكون هو أكبر عنصر تلقائياً ونرجعه فوراً: return list[lowerIndex];.
  • الحالة العامة (General Case): نقارن العنصر الأول في النطاق الحالي list[lowerIndex] مع أكبر عنصر في باقي المصفوفة largest(list, lowerIndex + 1, upperIndex) ونرجع الأكبر بينهما. في كل استدعاء يقل حجم النطاق بمقدار عنصر واحد.
int largest(const int list[], int lowerIndex, int upperIndex) {
    int max;

    if (lowerIndex == upperIndex) {
        return list[lowerIndex]; // Base Case
    } else {
        max = largest(list, lowerIndex + 1, upperIndex); // General Case

        if (list[lowerIndex] >= max)
            return list[lowerIndex];
        else
            return max;
    }
}
🔍 تفكيك الكود سطر بسطر وكلمة بكلمة (سلايد 22):

الوظيفة: ترويسة الدالة؛ تستقبل المصفوفة وفهرس البداية وفهرس النهاية، وترجع أكبر قيمة صحيحة.

int lowerIndex فهرس بداية النطاق الحالي للبحث.
int upperIndex فهرس نهاية النطاق الحالي للبحث.

الوظيفة: متغير محلي لحفظ أكبر قيمة عائدة من باقي المصفوفة.

الوظيفة: حالة الأساس (Base Case)؛ عندما يتساوى فهرس البداية مع فهرس النهاية نرجع هذا العنصر الوحيد مباشرة.

الوظيفة: استدعاء ذاتي يبحث عن أكبر رقم في بقية المصفوفة بدءاً من الخانة التالية lowerIndex + 1 حتى النهاية، ويخزن الناتج في max.

الوظيفة: مقارنة العنصر الحالي list[lowerIndex] مع أكبر عنصر في الباقي max وإرجاع القيمة الأكبر بينهما.

ثانياً: طباعة القائمة المتصلة بالمعكوس (Print Linked List in Reverse)

💡 المشكلة والحل الذكي بالـ Call Stack (سلايد 25 و 26):

في القائمة المتصلة الأحادية (Singly Linked List)، المؤشرات تسير في اتجاه واحد فقط للأمام، ولا يوجد مؤشر يرجع للخلف!

الحل بالـ Recursion: نستدعي الدالة للعقدة التالية reversePrint(current->next) أولاً، ونجعل أمر الطباعة cout مؤجلاً في السطر الذي يليه! وبذلك تتأجل طباعة كل عقدة في الـ Call Stack حتى نصل لنهاية القائمة (NULL)، وعند الرجوع تُطبع العقد من الأخيرة إلى الأولى تلقائياً! 

void reversePrint(Node* current) {
    if (current != NULL) {
        reversePrint(current->next); // 1. Recursive call FIRST
        cout << current->data << " "; // 2. Print AFTER return
    }
}

الوظيفة: دالة لا ترجع قيمة (void) لأن مهمتها الطباعة فقط، وتستقبل مؤشراً current يشير للعقدة الحالية.

if (current != NULL)

الوظيفة: فحص أننا لم نخرج بعد خارج نهاية القائمة. (أما عندما يصبح current == NULL فهذا هو الـ Base Case الضمني فتتوقف الدالة عن النداء).

reversePrint(current->next);

الوظيفة: السر كله هنا! الذهاب للعقدة التالية أولاً وتجميد العقدة الحالية في الـ Stack قبل طباعتها.

cout << current->data << " ";

الوظيفة: طباعة قيمة العقدة الحالية بعد أن تنتهي جميع العقد التي بعدها وتعود من الاستدعاء.

تريكة امتحانية هامة: لو عكسنا السطرين (كتبنا cout قبل reversePrint) ستُطبع القائمة بالترتيب العادي للأمام (5 10 15 20)!

تطبيق عملي: دمج دالتي largest و reversePrint في برنامج واحد

#include <iostream>
using namespace std;

int largest(const int list[], int lowerIndex, int upperIndex) {
    int max;
    if (lowerIndex == upperIndex) {
        return list[lowerIndex];
    } else {
        max = largest(list, lowerIndex + 1, upperIndex);
        if (list[lowerIndex] >= max)
            return list[lowerIndex];
        else
            return max;
    }
}

struct Node {
    int data;
    Node* next;
};

void reversePrint(Node* current) {
    if (current != NULL) {
        reversePrint(current->next);
        cout << current->data << " ";
    }
}

int main() {
    int arr[4] = {23, 43, 35, 20};
    cout << "Largest element in array: " << largest(arr, 0, 3) << endl; // 43

    Node* n1 = new Node{5, NULL};
    Node* n2 = new Node{10, NULL};
    Node* n3 = new Node{15, NULL};
    Node* n4 = new Node{20, NULL};
    n1->next = n2;
    n2->next = n3;
    n3->next = n4;

    cout << "Linked list in reverse: ";
    reversePrint(n1); // 20 15 10 5
    cout << endl;

    return 0;
}

struct Node { int data; Node* next; };

الوظيفة: تعريف هيكل العقدة الواحدة في القائمة المتصلة؛ تحتوي على القيمة data ومؤشر next يشير للعقدة التالية.

الوظيفة: إنشاء 4 عقد ديناميكية في الذاكرة بقيم (5، 10، 15، 20) وربط كل عقدة بالعقدة التي تليها.

new Node{5, NULL} حجز عقدة جديدة في الـ Heap تحمل الرقم 5 ومؤشرها الابتدائي NULL.
n1->next = n2; ربط مؤشر العقدة الأولى ليُشير إلى عنوان العقدة الثانية.
reversePrint(n1);

📌 الزتونة الامتحانية للمحاضرة الثالثة (Recursion)

1. مفهوم الـ Recursion وركيزتاه (سلايد 4 إلى 6)

التعريف: حل المشكلة عن طريق تقليصها إلى نسخ أصغر من نفسها (Reducing a problem to smaller versions of itself).

Base Case: حالة التوقف المباشرة التي تُنهي الاستدعاء.

General Case: الحالة المتكررة التي تنادي فيها الدالة نفسها بقيمة أصغر تقترب من الـ Base Case.

2. أنواع الـ Recursion والـ Infinite Recursion (سلايد 9 و 10)

• Direct: الدالة تنادي نفسها مباشرة.

• Indirect: دالة تنادي دالة ثانية، والثانية تنادي الأولى.

• Tail Recursion: الاستدعاء الذاتي هو آخر أمر يتنفذ في الدالة.

• Infinite Recursion: عدم الوصول للـ Base Case أبداً، مما يملأ الـ Call Stack ويسبب انهيار البرنامج (Stack Overflow / Abnormal Termination).

3. الدوال الأربعة الرسمية في المحاضرة الثالثة

1. المضروب fact(num): حالة التوقف num == 0 ترجع 1، والحالة العامة num * fact(num - 1).

2. فيبوناتشي rFibNum(a, b, n): لها حالتا توقف (n == 1 ترجع a، و n == 2 ترجع b)، وفي rFibNum(2, 3, 4) الناتج 8 ونصل للـ Base Case 3 مرات.

3. أكبر عنصر largest(list, lower, upper): حالة التوقف lowerIndex == upperIndex ترجع list[lowerIndex].

4. عكس القائمة reversePrint(current): تنادي reversePrint(current->next) قبل cout لتأجيل الطباعة في الـ Stack حتى النهاية.
