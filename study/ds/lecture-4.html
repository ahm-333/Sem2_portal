الفكرة الأساسية للـ Stack ويعني إيه ADT؟ (Slides 5 & 6)

Verbatim Slide 6 — BASIC IDEA:

"A stack is an Abstract Data Type (ADT), commonly used in most programming languages. It is named stack as it behaves like a real-world stack, for example – a deck of cards or a pile of plates, etc."

💡 يعني إيه Abstract Data Type (ADT) بالبلدي؟

• مصطلح ADT (نوع بيانات مجرد) معناه إننا بنوصف سلوك الهيكل والعمليات اللي بيعملها (نحط عنصر من فوق، نسحب عنصر من فوق) بغض النظر عن الطريقة اللي بنبرمجه بيها من جوة (سواء برمجناه بمصفوفة Array أو بقائمة متصلة Linked List).

🍽️ ليه سموه Stack (مكدس / رصة)؟

• لأنه بيتصرف بالظبط زي أي رصة في حياتنا اليومية (الشريحة 5 و 6):

1. رصة الأطباق في المطبخ (Pile of Plates): لما بتغسل طبق جديد بتحطه فوق الرصة، ولما تيجي تسحب طبق عشان تاكل فيه بتسحب أول طبق من فوق (مستحيل تسحب الطبق اللي تحت خالص وإلا الرصة كلها تقع تتكسر!).

2. كوتشينة الورق (Deck of Cards) أو الأحجار المرصوصة فوق بعضها: الإضافة والسحب دايماً بيحصلوا من قمة الرصة (Top) فقط.

4.1 ما هو الـ Stack؟ ومبدأ LIFO وإدارة استدعاء الدوال (Slide 7)

في الشريحة 7، يحدد الدكتور 3 نقاط جوهرية موضع سؤال مؤكد في كل امتحان:

1. "A stack in data structures is a linear collection of elements that follows a particular order in which the operations of addition and removal of elements are performed."

• الشرح: الـ Stack هو مجموعة خطية (linear) من العناصر بتلتزم بترتيب صارم ومحدد في طريقة إضافة العناصر (addition) أو حذفها (removal).

2. "The order is referred to as 'Last In, First Out' (LIFO). This means that the last element added to the stack is the first one to be removed."

• الشرح (أهم مصطلح في المحاضرة ⭐): هذا النظام يُسمى LIFO وهي اختصار لـ Last In, First Out (آخر من يدخل هو أول من يخرج). يعني آخر عنصر حطيته فوق الـ Stack هو أول عنصر هيطلع لما تيجي تسحب!

3. "Stacks are crucial for managing function calls in almost all programming environments, helping maintain the order of operations and execution seamlessly."

• الشرح: الـ Stack له دور حيوي جداً في كل لغات البرمجة وهو إدارة استدعاء الدوال (managing function calls)؛ لما دالة main() تنادي دالة A()، ودالة A() تنادي دالة B()، الكمبيوتر بيرصهم في Call Stack: آخر دالة اتنادت (B) هي أول دالة بتخلص وترجع، وبعدها A، وأخيراً نرجع لـ main!

سر الـ Stack كله هنا: العمليتان (push و pop) بتحصلان من طرف واحد فقط في الـ Stack بنسميه top (القمة). المتغير top دايماً بيشاور على مكان أعلى عنصر موجود حالياً في المكدس.

عملية Push بتضيف عنصر لقمة الـ Stack، وعملية Pop بتمسح عنصر من قمة الـ Stack، وهاتان العمليتان معاً هما اللتان تطبقان طريقة LIFO عملياً!

#include <iostream>
using namespace std;

const int MAX = 5; // Maximum size of the stack

class Stack {
private:
    int arr[MAX]; // Array to store stack elements
    int top;      // Index of the top element

public:
    Stack() {
        top = -1; // Stack is initially empty
    }

    // Check if stack is empty
    bool isEmpty() {
        return (top == -1);
    }

    // Check if stack is full
    bool isFull() {
        return (top == MAX - 1);
    }

    // Function to add an element to the stack
    void push(int value) {
        if (isFull()) {
            cout << "Stack Overflow! Cannot push " << value << endl;
        }
        else {
            arr[++top] = value;
            cout << value << " pushed into stack." << endl;
        }
    }

    // Function to remove the top element
    void pop() {
        if (isEmpty()) {
            cout << "Stack Underflow! Cannot pop." << endl;
        }
        else {
            cout << arr[top--] << " popped from stack." << endl;
        }
    }

    // Function to get the top element
    void peek() {
        if (isEmpty()) {
            cout << "Stack is empty." << endl;
        }
        else {
            cout << "Top element is: " << arr[top] << endl;
        }
    }

    // Display all elements in stack
    void display() {
        if (isEmpty()) {
            cout << "Stack is empty." << endl;
        }
        else {
            cout << "Stack elements (top to bottom): ";
            for (int i = top; i >= 0; i--) {
                cout << arr[i] << " ";
            }
            cout << endl;
        }
    }
};

int main() {
    Stack s;

    s.push(10);
    s.push(20);
    s.push(30);
    s.push(40);
    s.push(50);
    s.push(60); // Overflow

    s.display();

    s.pop();
    s.pop();

    s.peek();
    s.display();

    return 0;
}

#include <iostream>
using namespace std;

// Node structure
template <class T>
class Node {
public:
    T data;
    Node* next;
    Node(T value) {
        data = value;
        next = nullptr;
    }
};

// Stack class using Linked List
template <class T>
class Stack {
private:
    Node<T>* top; // Pointer to top node

public:
    Stack() {
        top = nullptr;
    }

    // Push operation
    void push(T value) {
        Node<T>* newNode = new Node<T>(value);
        newNode->next = top;
        top = newNode;
        cout << value << " pushed into stack." << endl;
    }

    // Pop operation
    void pop() {
        if (isEmpty()) {
            cout << "Stack Underflow! Cannot pop." << endl;
        }
        else {
            cout << top->data << " popped from stack." << endl;
            Node<T>* temp = top;
            top = top->next;
            delete temp;
        }
    }

    // Peek (top element)
    void peek() {
        if (isEmpty()) {
            cout << "Stack is empty." << endl;
        }
        else {
            cout << "Top element is: " << top->data << endl;
        }
    }

    // Check if stack is empty
    bool isEmpty() {
        return (top == nullptr);
    }

    // Display all elements
    void display() {
        if (isEmpty()) {
            cout << "Stack is empty." << endl;
        }
        else {
            cout << "Stack elements (top to bottom): ";
            Node<T>* temp = top;
            while (temp != nullptr) {
                cout << temp->data << " ";
                temp = temp->next;
            }
            cout << endl;
        }
    }

    // Destructor (Lines 80-85 explaining the last 4 output lines on Slide 35)
    ~Stack() {
        while (!isEmpty()) {
            pop();
        }
    }
};

int main() {
    cout << "Stack of Integers:\n";
    Stack<int> s1;
    s1.push(10);
    s1.push(20);
    s1.push(30);
    s1.display();
    s1.pop();
    s1.peek();

    cout << "\nStack of Strings:\n";
    Stack<string> s2;
    s2.push("AI");
    s2.push("Ethics");
    s2.push("Data");
    s2.display();
    s2.pop();
    s2.peek();

    return 0;
}

المقارنة النهائية الشاملة للامتحان: Stack as Array vs. Stack as Linked List

وجه المقارنة (Feature) Stack Using Array (بالمصفوفة) Stack Using Linked List (بالقائمة المتصلة)
نوع المتغير top رقم صحيح int top يحمل رقم الفهرس (Index) مؤشر عقدة Node<T>* top يحمل عنوان أول عقدة
قيمة top عند الإنشاء (فارغ) top = -1; top = nullptr; (أو NULL)
شرط isEmpty() return (top == -1); return (top == nullptr);
شرط isFull() (Stack Overflow) return (top == MAX - 1); (حجم ثابت) لا يمتلئ طالما توجد مساحة في الـ RAM (حجم ديناميكي)
كود الإضافة push(val) arr[++top] = val; — الوقت O(1) newNode->next = top; top = newNode; — الوقت O(1)
كود الحذف pop() arr[top--]; — الوقت O(1) temp = top; top = top->next; delete temp; — الوقت O(1)
كود القمة peek() arr[top] — الوقت O(1) top->data — الوقت O(1)
