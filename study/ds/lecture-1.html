1. ما هو هيكل البيانات؟ (1.1 Definition of Data Structure)

النص الأكاديمي الرسمي من السلايد:

Data Structure Definition: A Data Structure is a way of organizing and storing data in a computer so that it can be accessed and modified efficiently. It defines the relationship between data elements and the operations that can be performed on them.

💡 الشرح بالعامية البسيطة:

في علوم الحاسب، الكمبيوتر ميعرفش حاجة اسمها "قائمة أصدقاء" أو "سجل درجات طلاب"؛ المعالج (CPU) أثناء تشغيل أي برنامج معندوش غير شريط الذاكرة العشوائية (RAM).

هيكل البيانات (Data Structure) هو ببساطة: طريقة المهندسين في تنظيم وتخزين ورص البيانات جوة خلايا الـ RAM بهدفين أساسيين:

  1. تحديد العلاقة المنطقية بين البيانات: مين قاعد جنب مين، ومين قبل مين، ومين بعد مين.
  2. إمكانية عمل العمليات الأساسية: (زي القراءة، الإضافة، الحذف، والبحث، والترتيب) بأعلى سرعة وأقل استهلاك للميموري.

الأمثلة المذكورة في سلايد 3:

القوائم المتصلة Linked Lists
المكدس Stacks
الطوابير Queues
الأشجار Trees
الرسوم البيانية Graphs

2. المفهوم المجرد: ما هو الـ ADT؟ (1.2 Abstract Data Type)

النص الأكاديمي الرسمي من السلايد:

Abstract Data Type (ADT): An Abstract Data Type (ADT) is a mathematical model for a certain class of data structures that specifies the behavior (operations) of the data type without specifying how it is implemented.

• It focuses on WHAT operations are to be performed rather than HOW these operations are implemented.
• ADT provides a logical description of the data and the operations on it.
• ADT is a conceptual model; it hides the implementation details.

Examples of ADTs: Stack, Queue, List, Deque, Priority Queue, Set.

💡 الشرح بالعامية البسيطة:

الـ ADT ده هو المبدأ اللي بنسميه في هندسة البرمجيات Data Abstraction، يعني التجريد وإخفاء التفاصيل:

  • مثال التاكسي: تخيل إنك راكب تاكسي؛ أنت بتقول للسائق: "وديني الجامعة". دي العملية اللي أنت عايزها (WHAT). هل أنت بتشغل بالك هو هيغير التروس إزاي في الفتيس؟ أو الموتور هيحرق بنزين قد إيه؟ طبعاً لأ (HOW)؛ التفاصيل الميكانيكية دي مسؤولية السائق.
  • مثال زرار النور: عامل زي زرار النور في الحيطة؛ أنت عارف إنه لما تدوس عليه النور هيشتغل (WHAT)، لكن مبيشغلكش السلك جوة الحيطة متوصل إزاي بالكهرباء (HOW).

في البرمجة: الـ ADT يقولك: "أنا عايز هيكل بيعمل إضافة وقراءة وحذف"، ومبيشغلش باله نهائي بالتفاصيل الداخلية في الذاكرة. أما الـ Data Structure الفعلي هو اللي بيحدد هل هنستخدم مصفوفة متصلة (Array) ولا مؤشرات وقوائم (Linked List) لتنفيذ تلك العمليات.

🎨 رسم توضيحي: الفارق بين واجهة الـ ADT (ماذا نفعل) والتنفيذ الفعلي في الذاكرة (كيف ننفذ)

العمليات الأساسية الأربعة لأي ADT (سلايد 5):

1. الإضافة (Insertion)

إدخال عنصر جديد إلى هيكل البيانات (Adding new elements).

2. الحذف (Deletion)

إزالة عنصر موجود من هيكل البيانات (Removing existing elements).

3. الوصول والقراءة (Access / Retrieval)

قراءة وفحص واسترجاع قيمة عنصر معين (Reading or getting an element).

4. التعديل (Update / Modification)

استبدال أو تغيير قيمة عنصر مخزن بالفعل (Changing the value of an existing element).

3. أمثلة الـ ADTs الرسمية في السلايد (Stack & Queue)

ضربت السلايد مثالين شهيرين جداً لتوضيح كيف أن المفهوم المجرد يحدد فقط السلوك (Behavior):

أ) المكدس كـ ADT مجرد (The Stack ADT) — سلايد 6

Definition: A stack is a collection where elements are added and removed in a Last In, First Out (LIFO) order.
Implementation: Can be done using an array or linked list.
  • القاعدة (LIFO): آخر عنصر يدخل هو أول عنصر يخرج، زي بالظبط رصة الأطباق فوق بعضها؛ آخر طبق بتحطه على القمة هو أول طبق بتشيله.
  • التنفيذ في الـ RAM: مفهوم المكدس مجرد، ويمكن برمجته إما بمصفوفة (Array) أو بقائمة متصلة (Linked List).

ب) الطابور كـ ADT مجرد (The Queue ADT) — سلايد 7

Definition: A queue is a collection where elements are added at the rear and removed from the front: First In, First Out (FIFO).
Example: People waiting in a line → first person to come is first person served.
  • القاعدة (FIFO): أول عنصر يدخل الطابور هو أول عنصر يتم خدمته وخروجه (مثل طابور بنك أو سوبرماركت).
  • اتجاه الحركة: الإضافة بتتم من الخلف (Rear) والسحب والخروج بيتم من الأمام (Front).

4. الأنواع الأولية مقابل غير الأولية (1.3 Primitive vs. 1.4 Non-Primitive)

أ) الأنواع الأولية (Primitive Data Types) — سلايد 8:

التعريف: هي اللبنات الأساسية البسيطة المعرفة مسبقاً والمبنية داخل لغة البرمجة (Basic building blocks, predefined by the language).

الخصائص المذكورة نصاً في سلايد 8:

  1. تخزن قيمة مفردة واحدة فقط داخل المتغير (Stores single values).
  2. كفاءة عالية ومباشرة في استهلاك الذاكرة (Efficient in memory usage).
  3. معرفة مسبقاً في المترجم (Predefined by the language).

أمثلة: int float char double bool

ب) الأنواع غير الأولية / المركبة (Non-Primitive Data Types) — سلايد 9:

التعريف: هي هياكل أكثر تعقيداً يقوم المبرمج بإنشائها بنفسه أو تأتي بها المكتبات الجاهزة (Created by the programmer or provided by libraries).

الخصائص المذكورة نصاً في سلايد 9:

  1. غير معرفة مسبقاً بشكل بدائي (Not predefined, except some like String in Java).
  2. تخزن مجموعات من القيم معاً (Can store collections of values).
  3. يتم التعامل معها وتعديلها عبر دوال وطرق برمجية (Manipulated with methods/functions).
  4. تعتمد غالباً على المؤشرات وعناوين الذاكرة المباشرة (Typically reference types: store memory addresses instead of actual values).

أمثلة: المصفوفات (Arrays)، القوائم (Lists)، الأصناف (Classes)، المكدس (Stacks)، الطوابير (Queues)، الأشجار (Trees).

📊 جدول المقارنة الرسمي للامتحان (سلايد 8 و 9):

وجه المقارنة الأنواع الأولية (Primitive - سلايد 8) الأنواع المركبة (Non-Primitive - سلايد 9)
القيم المخزنة تخزن قيمة مفردة واحدة (Stores SINGLE values) تخزن مجموعات من القيم (Stores COLLECTIONS of values)
التعريف المسبق معرفة مسبقاً داخل اللغة (Predefined by the language) يبنيها المبرمج أو المكتبات (User-defined or libraries)
تمثيل الذاكرة تحمل القيمة الخام مباشرة (Holds raw value directly) غالباً أنواع مرجعية وعناوين (Typically reference types)
الكفاءة عالية الكفاءة ومباشرة في الذاكرة تتطلب هيكلية إضافية ودوال للتعامل معها
الأمثلة int, float, char, double, bool Arrays, Lists, Stacks, Queues, Trees

1. تصنيف هياكل البيانات: خطية مقابل غير خطية (Linear vs. Non-Linear DS)

تقسم السلايد هياكل البيانات إلى عائلتين رئيسيتين بحسب كيفية ترابط العناصر في الذاكرة:

أ) هياكل البيانات الخطية (Linear Data Structures - LDS) — سلايد 12:

A linear data structure is a structure in which elements are arranged sequentially, and each element is connected to its previous and next element (except the first and last).

الخصائص المذكورة نصاً في سلايد 12:

  1. العناصر مخزنة في ترتيب متتابع (Elements are stored in order).
  2. تنظيم أحادي المستوى (Single level organization).
  3. المرور على العناصر بسيط ومباشر خطوة تلو الأخرى (Traversal is simple: one after another).
  4. طريقة حجز الذاكرة قد تكون متصلة كالمصفوفات أو متفرقة بمؤشرات كالقوائم المتصلة (Memory can be contiguous like arrays or linked like linked lists).

الأمثلة: Arrays, Linked Lists, Stacks, Queues.

🎨 رسم توضيحي: الهيكل الخطي (مسار مستقيم متسلسل بمستوى واحد)

ب) هياكل البيانات غير الخطية (Non-Linear Data Structures - NLDS) — سلايد 14:

A non-linear data structure is a structure in which elements are not arranged sequentially. Each element can connect to multiple elements, forming a hierarchy or network.

الخصائص المذكورة نصاً في سلايد 14:

  1. العناصر ليست في ترتيب متتابع (Elements are not in order).
  2. تنظيم متعدد المستويات (Multi-level organization).
  3. المرور على العناصر يحتاج خوارزميات أكثر تعقيداً كالاستدعاء الذاتي والبحث بالعمق والاتساع (Traversal requires more complex algorithms like recursion, DFS, BFS).
  4. الذاكرة عادة ما تكون ديناميكية (Memory is usually dynamic).
  • الأشجار (Trees): تمثل علاقات هرمية متعددة المستويات (Hierarchy).
  • الرسوم البيانية (Graphs): تمثل شبكات معقدة متعددة المسارات (Network).

🎨 رسم توضيحي: الهيكل غير الخطي (شجرة هرمية متعددة المستويات — Tree)

📊 جدول مقارنة الهياكل الخطية وغير الخطية للامتحان (سلايدات 12 إلى 15):

وجه المقارنة الهياكل الخطية (Linear DS - سلايد 12) الهياكل غير الخطية (Non-Linear DS - سلايد 14)
ترتيب العناصر متسلسل ورا بعض (Sequential) غير متسلسل (Not sequential)
التنظيم والمستويات مستوى واحد فقط (Single-level organization) متعدد المستويات (Multi-level organization)
الترابط كل عنصر يتصل بالسابق والتالي فقط العنصر يرتبط بعدة عناصر (هرمي أو شبكي)
المرور على العناصر بسيط ومباشر في خط واحد (Simple loop) يحتاج خوارزميات معقدة (Recursion, DFS, BFS)
حجز الذاكرة متصلة (Contiguous) أو مترابطة (Linked) غالباً ديناميكية (Mostly dynamic)
الأمثلة Array, Linked List, Stack, Queue Tree (Hierarchy), Graph (Network)

2. المصفوفة أحادية البعد (1.6 One-Dimensional Array)

Array Definition (Slide 16): An array is a collection of elements of the same data type stored in contiguous memory locations.
All elements are accessed using an index. Indexing starts from 0 in C++.

💡 الشرح بالعامية البسيطة:

المصفوفة هي أقدم وأهم هيكل بيانات خطي في علوم الحاسب. المترجم لما بيشوف مصفوفة بيشترط 3 قواعد صارمة:

  1. نفس نوع البيانات (Same Data Type): مينفعش مصفوفة تشيل رقم صحيح مع نص مع حرف؛ لازم كلها أرقام int أو كلها حروف char.
  2. التخزين المتصل (Contiguous Memory): العناصر كلها بتنزل في الـ RAM محشورة ولازقة ورا بعضها مباشرة بدون أي مسافة أو فجوة بايت واحدة بينها!
  3. الفهرسة تبدأ من الصفر (Zero-based indexing): في لغة C++، أول عنصر في المصفوفة مكانه دايماً عند الفهرس رقم [0] وآخر عنصر عند [SIZE - 1].

3. السر الرياضي للوصول اللحظي O(1) بالمعادلة (Offset Address)

لماذا تستطيع المصفوفة قراءة أي عنصر بالرقم (arr[i]) في زمن ثابت لحظي O(1) دون الحاجة لأي حلقات تكرار أو بحث؟

لأن الذاكرة متصلة؛ فالمعالج (CPU) لا يبحث، بل يطبق معادلة حسابية مباشرة في خطوة واحدة:

Address(arr[i]) = Base_Address + (i × sizeof(Element))

مثال عملي من كواليس الـ RAM:

لنفترض أن لدينا مصفوفة أعداد صحيحة int arr[4]، حيث حجم كل int يساوي 4 بايت، وعنوان أول عنصر (Base Address) هو 2000:

  • أين يقع العنصر arr[2]؟ المعالج يحسب فوراً: 2000 + (2 * 4) = 2008 ويقفز للعنوان 2008 في دورة معالج واحدة!
  • لماذا يبدأ الفهرس من 0؟ لأن العنصر الأول يقع عند نقطة البداية مباشرة، وعدد خطوات القفز عنه يساوي صفر: 2000 + (0 * 4) = 2000.

1. ما هي القوالب؟ (1.9 Templates in C++)

Templates Definition & Purpose (Slide 42): • Definition: Templates allow writing generic and reusable code.
• Purpose: Write once, use with different data types.

Types of Templates:
1. Function Templates
2. Class Templates

Three Official Benefits:
1. Code reusability
2. Type safety
3. Performance (Compile-time resolution)

💡 الشرح بالعامية البسيطة:

في لغة C++ العادية، لو كتبت دالة int add(int a, int b) فهي مقيدة بالأعداد الصحيحة فقط. لو أردت جمع double أو string كنت ستضطر لتكرار كتابة الدالة!

الحل هو القوالب (Templates): تكتب الكود مرة واحدة فقط باستخدام نوع بيانات رمزي عام (Generic Type) وليكن T، وعند استدعاء الدالة يكتشف المترجم (Compiler) النوع تلقائياً ويولد النسخة المناسبة وقت الترجمة (Compile-time) بدون أي بطء أثناء التشغيل.

2. تشريح كود قالب الدالة (Function Template) وقالب الصنف (Class Template):

#include <iostream>
using namespace std;

// 1. قالب دالة عام (Function Template)
template <typename T>
T findMax(T a, T b) {
    if (a > b)
        return a;
    else
        return b;
}

// 2. قالب كلاس عام (Class Template)
template <typename T>
class Box {
private:
    T item;
public:
    void setItem(T val) { item = val; }
    T getItem() { return item; }
};

int main() {
    cout << findMax(10, 20) << endl;
    cout << findMax(3.14, 2.71) << endl;

    Box<int> intBox;
    intBox.setItem(100);

    Box<string> strBox;
    strBox.setItem("Data Structures");
    return 0;
}
🔍 تفكيك الكود سطر بسطر وكلمة بكلمة:
template <typename T>

الوظيفة: إعلان للمترجم أن الدالة أو الكلاس التالي هو قالب عام يستخدم نوع بيانات رمزي اسمه T.

template الكلمة المحجوزة الأساسية في C++ لإنشاء قالب.
< > قوسا معاملات القالب (Template Angle Brackets).
typename كلمة محجوزة تعني أن الرمز التالي هو "اسم نوع بيانات" (ويمكن استبدالها بالكلمة class).
T الاسم الرمزي للنوع العام (Type Parameter) الذي سيستبدله المترجم لاحقاً بـ int أو double أو string.
T findMax(T a, T b)

الوظيفة: ترويسة دالة عامة تقبل معاملين من النوع T وترجع الناتج الأكبر من نفس النوع T.

T (الأولى) نوع القيمة الراجعة من الدالة (Return Type).
findMax اسم الدالة.
(T a, T b) معاملان a و b كلاهما من نفس النوع العام T.
class Box { private: T item; ... };

الوظيفة: تعريف كلاس عام اسمه Box يمتلك متغيراً داخلياً item نوعه يتحدد عند إنشاء الكائن.

void setItem(T val) دالة لتخزين قيمة من النوع T داخل الصندوق.
T getItem() دالة لإرجاع القيمة المخزنة من النوع T.
Box<int> intBox;

الوظيفة: إنشاء كائن اسمه intBox من القالب Box مع تحديد النوع الحقيقي بـ int.

Box<string> strBox;

الوظيفة: إنشاء كائن ثانٍ من نفس الكلاس لكنه مخصص لتخزين النصوص string بدون إعادة كتابة الكلاس!

    int x = 5, y = 10;
    mySwap(x, y);
    cout << "After swapping ints: x = " << x << ", y = " << y << endl;

    double p = 1.5, q = 9.8;
    mySwap(p, q);
    cout << "After swapping doubles: p = " << p << ", q = " << q << endl;

    return 0;
}
🔍 تفكيك الكود سطر بسطر وكلمة بكلمة:
void mySwap(T &a, T &b)

الوظيفة: استلام متغيرين من النوع T بالمرجع (Pass by Reference) لتبديل قيمتيهما الأصليتين في الـ RAM.

void الدالة لا ترجع قيمة لأنها تعدل المتغيرين الأصليين مباشرة.
T &a علامة & تعني Reference (مرجع للعنوان الأصلي في الذاكرة)، وبدونها لن يتأثر المتغيران في main.
T temp = a; a = b; b = temp;

الوظيفة: خوارزمية التبديل الثلاثية باستخدام متغير مؤقت temp من نفس النوع العام T.

T temp = a; حفظ قيمة a مؤقتاً داخل متغير مساعد temp من نفس النوع T حتى لا تضيع.
a = b; نقل قيمة b إلى داخل a.
b = temp; وضع القيمة المحفوظة في temp داخل b.
mySwap(x, y); / mySwap(p, q);

الوظيفة: استدعاء نفس القالب مرة مع أعداد صحيحة (int) ومرة مع أعداد عشرية (double) فيولد المترجم النسختين تلقائياً.

📌 ملخص المحاضرة الأولى بالكامل مراجعة سريعة مركزة قبل الحل

📌 الزتونة الامتحانية للمحاضرة الأولى (سلايد 3 إلى 44)

1. Data Structure vs. ADT (سلايد 3 إلى 5)

هيكل البيانات (Data Structure): طريقة تنظيم وتخزين البيانات في الـ RAM للوصول إليها وتعديلها بكفاءة، وتحدد العلاقات والعمليات.

المفهوم المجرد (ADT): نموذج رياضي مجرد يحدد WHAT (ما هي العمليات: Insertion, Deletion, Access, Update) ويخفي HOW (تفاصيل البرمجة والتنفيذ).

2. Stack vs. Queue (سلايد 6 و 7)

المكدس (Stack): يعمل بقاعدة LIFO (Last In, First Out) — آخر داخل هو أول خارج.

الطابور (Queue): يعمل بقاعدة FIFO (First In, First Out) — الإضافة من الخلف (Rear) والحذف من الأمام (Front).

3. Primitive vs. Non-Primitive & Linear vs. Non-Linear (سلايد 8 إلى 15)

الأنواع الأولية (Primitive): معرفة مسبقاً باللغة وتخزن قيمة مفردة واحدة (int, float, char, bool).

الأنواع المركبة (Non-Primitive): تخزن مجموعات من القيم وغالباً عناوين مرجعية (Arrays, Lists, Stacks, Trees).

الهياكل الخطية (Linear DS): عناصر متتالية في مستوى واحد (Array, Linked List, Stack, Queue).

الهياكل غير الخطية (Non-Linear DS): متعددة المستويات، هرمية أو شبكية (Trees, Graphs).

4. قواعد المصفوفات 1D & 2D & Multi-D (سلايد 16 إلى 40)

• عناصر من نفس النوع في ذاكرة متصلة (Contiguous Memory)، والفهرسة تبدأ من 0 إلى SIZE - 1، والوصول يأخذ O(1).

• العناصر غير المهيأة تأخذ تلقائياً 0 أو NULL.

• عند تمرير مصفوفة ثنائية أو متعددة الأبعاد لدالة: يُسمح بترك البُعد الأول فقط فارغاً ويجب تحديد باقي الأبعاد (الأعمدة) إجبارياً مثل void fn(int arr[][COLS]) أو void fn(short arr[][3][5]).

5. القوالب Templates (سلايد 41 إلى 44)

• الغرض: Write once, use with different data types عبر الكلمة المحجوزة template <typename T>.

• الفوائد الثلاث الرسمية: Code reusability + Type safety + Performance (compile-time resolution).
